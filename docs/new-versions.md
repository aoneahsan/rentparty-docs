Rent Party keeps your unfinished table while the game itself changes. A new version can update the browser game or the Android app; the notice tells you which version is ready and why the team released it.

## Why did I get an update notice? {#notice}

A normal release first offers **Update now** or **Later**. If you choose Later, you can finish what you're doing. The next time you start Rent Party, that release is required before you play. The notice shows the new version, so you know what you're accepting.

## Why is the update required now? {#required}

An urgent release blocks immediately. A normal release blocks from your next start after the first notice. The screen shows your current version, the new version and the team's reason when one was recorded. There is one **Update** button; in the Android app, **Open Google Play** is also available.

Your games are saved. You'll pick up where you left off after updating.

## What does Update do? {#what-update-does}

In a browser, **Update** loads the newer site build. On Android, the app applies a newer game bundle when that release supports it. If the release needs a newer installed app, it opens the store update instead. The [apps page](./apps.mdx) has the current browser and Google Play links.

## What if the update does not start? {#store}

Check your connection and press **Update** again. On Android, use **Open Google Play** if the in-app update could not start. If the screen keeps returning, [ask the Rent Party team](./help.md) and include the two version numbers shown on it. The [developer changelog](./developers/changelog.md) records changes to the API, MCP server and webhooks; it is separate from the game version notice.
