Aquí aparecen los cambios de la API, el servidor MCP y los webhooks, empezando por el más reciente. La versión de la API forma parte de su dirección, `/v1`, y el [archivo OpenAPI](./api.md#reference) siempre describe la versión bajo la que se publica.

Los cambios de la documentación se publican en [Novedades](/blog).

## 19 de noviembre de 2026 {#2026-11-19}

- Se añadieron tokens de acceso en Ajustes → Otras aplicaciones; la API `/v1` y su archivo OpenAPI; el servidor MCP para asistentes de IA; webhooks para partidas terminadas, insignias y partidas guardadas; y la verificación en dos pasos en Ajustes → Seguridad.
