Nadie tiene que dejar Board Game Arena. Allí hay cientos de juegos; Rent Party tiene uno. Ven para una noche de compraventa de propiedades y conserva tu cuenta allí para todo lo demás.

Aquí no necesitas un plan para abrir una mesa. También puedes pasar el celular entre jugadores, enfrentarte a personajes CPU y crear salas en línea.

## Tu Premium y tu historial \{#move}

Ambos se quedan en Board Game Arena.

## Jugar por turnos, como ya juega tu grupo \{#table}

1. Inicia sesión con Google en [Iniciar una partida](https://rentparty.aoneahsan.com/play) y elige En línea.
2. Elige Por días y un plazo de 8, 12, 24 o 48 horas [por turno](../online-play.md#modes).
3. Envía la [invitación](../online-play.md#invites). Tu plan no decide si puedes abrir una mesa; [sus límites](../plans-and-pricing.md#limits) determinan cuántas puedes tener a la vez.

## ¿Un juego diferente cada semana? \{#stay}

Entonces Board Game Arena te ofrece más opciones: ya tiene mesas en vivo y por turnos para cientos de juegos.

## Los datos de ambos \{#facts}

Board Game Arena describe un modo Premium para jugar en un solo dispositivo. Sus páginas no decían si tiene jugadores de computadora, pausas, aspectos para coleccionar, editor de tableros, aplicaciones para Android o iOS, ni anuncios de terceros. Por eso no incluimos esas filas.
