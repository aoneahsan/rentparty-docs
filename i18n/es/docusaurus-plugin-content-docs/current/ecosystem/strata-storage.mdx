Usa una sola interfaz de almacenamiento para las partidas guardadas en la web y en dispositivos nativos.

## ¿Qué hace Strata Storage? \{#strata-storage-fact-1}

Strata Storage ofrece una API para localStorage, IndexedDB, cookies y almacenamiento nativo.

## ¿Qué más puede hacer Strata Storage? \{#strata-storage-fact-2}

No tiene dependencias y funciona en la web, iOS y Android.
