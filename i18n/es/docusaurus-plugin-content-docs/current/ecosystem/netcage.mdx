Deja una aplicación Android sin conexión mientras el resto del teléfono sigue en línea.

## ¿Qué hace NetCage? \{#netcage-fact-1}

NetCage puede bloquear Wi-Fi y datos móviles para una aplicación Android concreta sin desconectar el resto del teléfono.

## ¿Qué más puede hacer NetCage? \{#netcage-fact-2}

Una regla puede afectar a Wi-Fi, a los datos móviles o a ambos.
