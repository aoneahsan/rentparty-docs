Una misma forma de iniciar sesión con Google en las pantallas por las que pasa tu juego.

## ¿Qué hace Capacitor Auth Manager? \{#capacitor-auth-manager-fact-1}

Capacitor Auth Manager ofrece una sola llamada para iniciar sesión con Google en la web, Android e iOS.

## ¿Qué más puede hacer Capacitor Auth Manager? \{#capacitor-auth-manager-fact-2}

No exige Firebase como dependencia.
