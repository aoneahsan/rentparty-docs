Mantén cerca a las personas que eliges entre noches de juego, sin dar tu número de teléfono.

## ¿Qué hace AchatAI? \{#achat-fact-1}

AChat es una aplicación de mensajería para la web y Android, pensada para hablar con las personas que eliges.

## ¿Qué más puede hacer AchatAI? \{#achat-fact-2}

Puedes encontrar a alguien por su nombre de usuario, un enlace de invitación o un código QR, sin pedirle su número.
