访问令牌是一段较长的密钥，代码在每次请求中通过`Authorization: Bearer <token>`发送。你在**设置 → 其他应用**中创建令牌，选择它可读取什么、何时到期，并可随时撤销。代你连接的应用则使用OAuth，不需要你把令牌交给它。

## 怎样创建令牌？ {#make-a-token}

1. 打开**设置 → 其他应用 → 访问令牌**，选择**新令牌**。
2. 起个一个月后仍能认出的名字。*游戏夜电子表格*比*令牌1*好记。
3. 选择权限范围和有效期。
4. 令牌只显示一次，旁边有复制按钮。关闭面板前，请安全保存。

之后列表会显示每个令牌的名称、权限范围、开头几个字符、创建时间和最近使用时间，不会显示完整令牌。每次创建令牌，你都会收到邮件，因此不是你创建的令牌也不容易漏掉。

## 还能重新查看令牌吗？ {#reveal}

可以，但必须在**最近一次登录后的10分钟内**。在令牌所在行选择**显示**：

| 情况 | 结果 |
|---|---|
| 登录未满10分钟 | 显示令牌。 |
| 登录已超过10分钟 | Rent Party会说明情况，并提供**重新登录**，完成后返回同一行。 |
| 已开启两步登录 | 即使还在10分钟内，也需输入身份验证器应用的验证码。 |

为什么这么谨慎？长时间保持登录很方便，但借出去的手机也可能保持登录。再次登录能证明请求显示令牌的人是你。每小时最多显示10次，每次都会记入账号记录；令牌绝不会通过邮件发送。

## 权限范围是什么意思？ {#scopes}

你记录中的每一部分都有读取权限。已保存游戏还有一项额外权限：

| 权限范围 | 允许令牌 |
|---|---|
| `<part>:read` | 读取你的个人资料和统计、已结束游戏结果、徽章和评分历史，或已保存游戏 |
| `saved_games:delete` | 删除你已保存的一局游戏 |

没有权限范围能修改游戏、个人资料或结果。准确的权限名称见[OpenAPI文件](./api.md#reference)。

**读取不代表能删除。**读取已保存游戏的令牌不能自动删除它们。删除权限在界面上单独列出，默认未勾选。令牌创建后，权限范围不能扩大；需要更多权限时，请创建新令牌并撤销旧令牌。令牌永远不能拥有团队权限。

## 令牌有效期有多久？ {#expiry}

你可以选择**30、90或365天**。到期前7天，Rent Party会发邮件提醒。到期后，使用该令牌的请求都会返回`401`。

## 怎样更换或撤销令牌？ {#rotate-and-revoke}

- **轮换**会创建新令牌。旧令牌继续有效24小时，方便你更新代码，之后会被撤销。期间两枚令牌都会出现在列表中。
- **撤销**会立即停用令牌。下一次使用它的请求会返回`401`。需要按两次确认，没有弹窗。

删除Rent Party账号时，所有令牌、已连接应用和Webhook也会一并撤销。

## 应用怎样不用令牌也能连接？ {#oauth}

通过OAuth 2.1，方式与AI助手登录相同。应用会带你前往Rent Party的授权页面`https://rentparty.aoneahsan.com/oauth/consent`，页面会显示：

- 应用名称，以及完成后返回的地址；
- 即将访问的Rent Party账号；
- 申请的权限，以通俗语句列出，读取和删除分别成组、各有勾选框，删除默认不勾选；
- 并排的**批准**和**拒绝**按钮。

开启两步登录后，批准时还需验证码。应用随后会出现在**设置 → 其他应用 → 已连接应用**中，可以重命名或撤销。撤销后，它的下一次请求即失去访问权。详情见[AI助手](./mcp.md#consent)。

## 可以发送多少请求？ {#rate-limits}

每枚令牌和每个已连接应用**每分钟可发送120次请求**。账号还有由套餐决定的每日总量，所有令牌和应用共享，因此多创建令牌不会提高总量。“设置 → 其他应用”会在当天计数旁显示套餐额度。

每次响应都带有三个标头：

| 标头 | 含义 |
|---|---|
| `RateLimit-Limit` | 当前窗口允许的请求数 |
| `RateLimit-Remaining` | 当前窗口剩余的请求数 |
| `RateLimit-Reset` | 距下个窗口开始还有多少秒 |

超过上限会收到`429`和`Retry-After`标头。等待标明的秒数后再试。

如果同一瞬间发出大量请求，托管平台可能在Rent Party收到之前就返回`546`。请依次发送或分成小批量；遇到`546`时等一秒后重试。

## 错误响应长什么样？ {#errors}

所有路由的错误都采用同一种格式：

```json
{
  "error": {
    "code": "reauth_required",
    "message": "Sign in again to see this token.",
    "details": { "max_age_seconds": 600 },
    "correlation_id": "…"
  }
}
```

代码应根据`code`处理错误。`message`供人阅读，措辞可能变化。向团队咨询失败请求时，请提供`correlation_id`，方便我们找到对应的那一次请求。

| 状态码 | 常见原因 |
|---|---|
| `401` | 未提供令牌，令牌错误、已撤销或已过期 |
| `403` | 令牌缺少权限（`details`会说明），或需要重新登录 |
| `404` | 你的记录中找不到该ID；属于别人的内容同样返回此状态 |
| `429` | 达到请求上限，见`Retry-After` |

完整错误代码列表见[OpenAPI文件](./api.md#reference)。
