你不必离开Board Game Arena。那里有数百款游戏，而Rent Party只有一款。想来一场地产交易之夜，就来这边开桌；其他游戏仍可以继续在那里玩。

在这里，不用购买套餐就能开桌。除了在线房间，还能围着一部手机轮流玩，或挑战电脑角色。

## 你的Premium资格和游戏记录 \{#move}

它们仍留在Board Game Arena。

## 按你们熟悉的节奏轮流玩 \{#table}

1. 在[开始游戏](https://rentparty.aoneahsan.com/play)页面用Google登录，选择“在线”。
2. 选择“跨日对局”，并为[每回合](../online-play.md#modes)设置8、12、24或48小时的时限。
3. 发出[邀请](../online-play.md#invites)。是否能开桌不取决于套餐；[套餐上限](../plans-and-pricing.md#limits)决定同时能进行多少局。

## 每周都想换一款游戏？ \{#stay}

那Board Game Arena更适合你：它已经为数百款游戏准备了实时和回合制棋桌。

## 两款游戏的资料 \{#facts}

Board Game Arena介绍了Premium会员可在同一设备上轮流玩的模式。其页面没有说明是否有电脑玩家、暂停、可收集的外观、自制棋盘、Android或iOS应用，以及第三方广告，因此这些条目没有列入下方对比。
