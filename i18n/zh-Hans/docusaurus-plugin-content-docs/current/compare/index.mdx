原有内容不用搬。玩一款桌游无需迁移游戏记录；来到Rent Party，只需要把朋友请到棋桌旁。下面每份指南都会讲清怎么开始，也会告诉你什么情况下继续玩原来的游戏更合适。

每项价格与功能都根据对方游戏自己的页面核查。最近核查日期：2026年11月27日。想并排看两款游戏的详细对比，请到[Rent Party网站的对比中心](https://rentparty.aoneahsan.com/compare)。

## 我们目前还没有什么？ \{#limits}

先说清楚：Rent Party目前没有棋盘编辑器，也没有iOS应用；在iPhone上可以用浏览器玩。Android应用已上架Google Play。游戏里没有第三方广告，但部分页面有一个小区域介绍我们的其他应用。

选好方式就可以开始：[开始游戏](https://rentparty.aoneahsan.com/play)。
