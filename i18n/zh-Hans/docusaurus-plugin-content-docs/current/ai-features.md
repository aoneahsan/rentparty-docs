交易到一半想查规则，或想知道昨晚那局是怎么输的？Rent Party的AI功能可以帮你。每项功能只会在你点按钮或打开开关后运行。不用它们，游戏照样能玩。

无论你怎样设置开关，电脑角色都按游戏自身规则行动。新对话只改变他们说什么，不会改变他们怎么玩。

## 有哪些AI功能？ {#overview}

一共五项，都等着你主动使用：帮助助手、战局回顾、交易分析、新的棋桌对话和语音录音。下面列出入口与结果。

| 功能 | 在哪里找到 | 会得到什么 |
|---|---|---|
| 帮助助手 | 游戏[帮助页面](https://rentparty.aoneahsan.com/help)上的**提问**，或游戏暂停菜单 | 根据这份文档和帮助页面回答，并列出依据的页面 |
| 战局回顾 | 已结束在线对局的结果和回放中，**这局怎么打的**下方的**写战局回顾** | 一段简短的对局故事，所有参赛者看到同一份 |
| 交易分析 | 任意游戏交易窗口中的**分析这笔交易** | 对颜色组、租金和游戏现金的影响，以及一条建议 |
| 新的棋桌对话 | “设置”中的**每局生成新台词** | 为这局游戏写给电脑角色的新台词 |
| 语音录音 | 帮助页面的**语音提问**、手机上的麦克风按钮，或交易窗口的**口述报价** | 识别成问题、给团队的消息或交易报价，发送前由你核对 |

## 帮助助手怎样运作？ {#help-assistant}

它只根据Rent Party文档和游戏帮助页面回答。每条回答下的**依据页面**会列出参考页面，方便你打开核对。回答仍可能出错，应以所列页面为准。

在游戏帮助页面选择**提问**。游戏暂停菜单也有相同按钮。输入问题，或选一个示例，例如“怎样离开监狱？”像问同桌朋友那样提问就好。

如果文档没有涉及你的问题，它会如实说明，并提供**给团队留言**。这种情况不计入当天提问次数。[怎样联系团队？](./help.md#write-to-the-team)介绍了留言时该提供什么。

## 战局回顾怎样运作？ {#recaps}

战局回顾用一小段故事讲完一局在线游戏：谁赢了、打了多少轮、胜负有多接近。如果你参加过这局，在结果页第一张卡片下方，以及回放中，都能找到**这局怎么打的**。选择**写战局回顾**。

内容只会根据游戏记录写一次，同桌玩家读到的是同一份。只有发起生成的玩家会用掉当月一次额度。阅读已经生成的回顾不消耗额度，所以不用抢着点，再战之前也能重读。

战局回顾只适用于在线对局。同设备对局和访客都不能生成。生成后，它会随游戏保存。

## 交易分析怎样运作？ {#trade-read}

在交易窗口填好报价，再选择**分析这笔交易**。游戏会算出：

- 双方分别凑齐或拆散了哪些颜色组；
- 转手地契涉及多少租金；
- 交易后双方各有多少游戏现金。

写作服务会根据这些事实给出简短建议，例如：“这会让Maya凑齐一整组；其中没有建筑的街道租金会翻倍。可以多要些游戏现金，或者留下那张地契。”

这只是建议，是否提出报价由你决定。不读分析，报价也照样能发送。至少先在一方放入一项内容；空白报价无从分析。

## 棋桌对话怎样运作？ {#table-talk}

电脑角色会在棋桌发生事情时说话：买地、付租、交易或进监狱。停在Bea的街道上，你肯定会听到她的意见：“你走到我的街上了？真巧。”

“设置”中的“外观”下有三个开关，决定你怎样听到他们：

| 开关 | 默认 | 作用 |
|---|---|---|
| 电脑角色开口说话 | 开 | 浏览器或手机上的声音会念出台词，每个角色的音调和语速都不同。 |
| 显示台词 | 开 | 在角色座位旁显示约3秒的对话气泡。 |
| 每局生成新台词 | 关 | 写作服务为这一局写新台词。关闭时，角色使用设备上已有的原创台词。 |

关闭前两个开关，电脑角色就会安静地玩。游戏暂停菜单也有**电脑角色语音**开关，不用离开棋桌就能关掉说话声。登录后，你的开关设置会跟随到其他设备。浏览器或手机没有可用语音时，仍会显示对话气泡。

第一次在某台设备上和电脑角色玩时，棋桌旁的小卡片会询问是否开启新台词。选择**开启**或**暂不**；以后随时可在“设置”中更改。新台词有每局的用量，在同设备轮流玩和电脑对局中按天计算。用完后，角色会回到原有台词。

六位对手都列在[电脑角色](./how-to-play/cpu-characters.md)页面。

## 语音录音怎样运作？ {#voice}

不想打字就说出来。在游戏帮助页面选择**语音提问**。手机上的首页、你的游戏和帮助页面，右下角有圆形麦克风按钮。在游戏交易窗口中，可以选择**口述报价**。

按**开始**后，最多说2分钟。第一次使用时，手机或浏览器会请求麦克风权限。只有面板显示**录音中**时，Rent Party才会收音；停止后会释放麦克风。

选择**停止并核对**，录音会整理成以下其中一项：

- 向帮助助手提出的问题；
- 发给团队的消息，附带主题；访客需填写邮箱，团队才方便回复；
- 交易报价，会在交易窗口打开，你可以修改。

在你按下发送按钮之前，任何内容都不会发送。

更想打字？麦克风被禁用或录音失败时，选择**改为输入**就能切换到文字版。

## 语音录音会保留吗？ {#voice-kept}

不会保留太久。在**识别到的内容**下选择**删除这段录音**，可以立即删除。否则，录音、识别出的文字及生成的内容都会在24小时内删除。其他玩家听不到录音，也看不到识别结果。隐私政策说明了[语音录音如何处理](https://rentparty.aoneahsan.com/privacy#voice-recordings)。

## 各项功能会发送什么？ {#what-is-sent}

只发送该功能必需的内容，而且只在你主动使用时发送。请求由我们的服务器发出，不会从你的设备直接发送，因此不包含你的名字、邮箱或账号背后的随机标识。

- **帮助助手：**你的问题，以及最相关的文档页面文字。
- **战局回顾：**游戏结果，例如各座位的名次、净资产、支付及收取的租金。座位只用“玩家1”“玩家2”或电脑角色名字表示，不用玩家昵称。
- **交易分析：**报价内容，以及双方交易前后的游戏现金。不包含骰子或卡牌顺序。
- **新台词：**角色名字与简短性格介绍，以及每个时刻发生了什么、发生在哪个座位。不发送金额或玩家名字。
- **语音录音：**音频送往转写服务；随后，转写结果、浏览器识别结果及录音所在页面会送往写作服务。在网站上，如果你说话时屏幕会同步显示文字，浏览器自己的语音服务也会处理声音。Android应用不使用该浏览器服务。

删除之前，录音会作为私密文件暂存在我们自己的邮件和文件服务中。朗读台词只使用你设备上的声音。朗读时不会发送内容；浏览器或手机没有语音功能时，只显示对话气泡。

我们不保留你的问题、回答或交易分析。战局回顾会随游戏保存。隐私政策列出了各项服务及发送内容：[AI功能发送什么，发送到哪里？](https://rentparty.aoneahsan.com/privacy#ai-features) [隐私与条款](./privacy-and-terms.md#privacy)也概述了相关内容。

## AI等级是什么？ {#levels}

Spark、Pulse和Surge是三个AI等级，决定帮助回答、战局回顾和交易分析会投入多少推理。Spark响应快，Pulse更深入，Surge最深入。

| 套餐 | AI等级 |
|---|---|
| 访客或Free | Spark |
| Pro | 先为Pulse，连续付费达到价格页面所列月数后升至Surge |
| Family | Surge |

Pro只有实际付费月份计入升至Surge的进度，好友邀请获得的月份不算。漏掉一个付费月，进度会重新计算；不过两个付费月之间的短暂间隔仍可保持续计。[你的套餐页面](https://rentparty.aoneahsan.com/plan)会显示当前进度。

AI等级是套餐可使用的最高等级。如果可用AI额度暂时不足，功能可能短时间降到较低等级。[套餐与价格](./plans-and-pricing.md#ai-level)进一步介绍套餐。

## 每项功能可以用多少？ {#allowances}

每个套餐都包含各项功能的用量，Pro和Family额度更高。[价格页面](https://rentparty.aoneahsan.com/pricing)列出当前数值，套餐页面会显示你已使用的数量。

| 功能 | 计算周期 |
|---|---|
| 向帮助助手提问 | 每天 |
| 战局回顾 | 每月 |
| 交易分析 | 每天 |
| 新棋桌对话 | 每局游戏（同设备轮流玩和电脑对局按天） |
| 语音录音 | 每月 |

日期按协调世界时（UTC）计算，所以新的每日提问额度不一定在你的午夜恢复。功能面板会显示恢复时间。

某项功能用量耗尽后，需要等到下一天、下个月或下一局；其余部分照常使用：文档仍可阅读，交易报价仍可发送，也能继续打字。文档无法回答的问题不计次数；没有得到结果的请求也不计。

## 访客能使用这些功能吗？ {#guests}

可以，除了战局回顾，其他功能都能以Spark等级使用。访客额度按Free套餐数值计算，每天重置。每个功能面板会显示今天的剩余额度。

每次请求前，系统会快速确认你是真人。隐私政策说明[访客使用AI功能时Rent Party会保留什么](https://rentparty.aoneahsan.com/privacy#guests-and-ai)。

## AI功能暂时休息时会怎样？ {#resting}

AI功能使用免费的AI额度。额度用完时，它们会暂时休息。休息期间不会产生费用，每个功能面板都会显示额度恢复时间。游戏照常继续：

- 帮助助手会引导你查看文档或联系团队；
- 战局回顾可以稍后生成，游戏记录仍在；
- 交易报价仍可发送，只是暂时没有分析；
- 语音录音需等待，也可以改为打字；
- 电脑角色会使用原有的台词。

## 怎样关闭电脑角色语音？ {#settings}

想让电脑角色安静些，可以在“设置”→“外观”关闭**电脑角色开口说话**，或从暂停菜单关闭**电脑角色语音**。“设置”里还有另外两个棋桌对话开关。帮助助手、战局回顾、交易分析和语音不需要关闭开关；你按下对应按钮时，它们才会运行。

想禁用麦克风，可以在手机或浏览器设置中禁止Rent Party使用。[权限页面](https://rentparty.aoneahsan.com/permissions#microphone)说明了麦克风的使用时机。
