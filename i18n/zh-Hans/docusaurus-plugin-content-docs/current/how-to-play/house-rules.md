开局前可以选一套预设，也可以逐条开启自定义规则。在[开始游戏](../intro.md#start-a-game)的“自定义规则”步骤中设置。

:::note[本页数值]

这里的数值对应游戏的当前设置。游戏内的[玩法说明](https://rentparty.aoneahsan.com/how-to-play)始终显示最新信息。

:::

## 有哪些预设？ {#presets}

| 预设 | 启用的规则 |
|---|---|
| 官方 | 经典规则，所有自定义规则都关闭。 |
| 家庭经典 | 存钱罐、恰好停在起点的奖金，以及随时交易。 |
| 快速 | [获胜规则](./rules.md#winning)中介绍的短局模式。 |
| 锦标赛 | 官方规则，但始终执行回合和决策计时。 |

## 可以开启哪些自定义规则？ {#house-rules}

| 自定义规则 | 作用 |
|---|---|
| 存钱罐 | 支付给银行的税、费用和卡牌罚款都存进去，包括修理费；停在市民广场的玩家拿走全部。 |
| 起点停靠奖金 | 恰好停在起点时，额外获得200游戏现金。 |
| 仅在自己回合交易 | 只能在自己的回合提出交易。 |
| 游戏时长上限 | 达到指定轮数或分钟数后，净资产最高者获胜。 |
| 无拍卖 | 没人购买的街道继续归银行。 |
| 起始现金和工资 | 自行选择金额。 |
| 城市税选项 | 停在城市税时，选择支付200游戏现金或净资产的10%；必须在计算前选定一种。 |
| 暗标拍卖 | 适用于实时和本地游戏，详情见[拍卖规则](./rules.md#auctions)。围着一部设备玩时，每人秘密输入出价，再把设备传给下一人。 |
| 快速成交 | 每人开局从银行随机获得2张地契。 |
| 服刑期满 | 在监狱连续三次没有掷出双骰，就可以免费离开，不用交罚金。 |

如果你家以前总把税款堆在棋盘中央，谁停在那块安静的角落就拿走它，存钱罐就是这条规则。

## 哪些规则可用于计分对局？ {#rated-games}

只有“官方”和“锦标赛”。在线计分对局必须由真人坐满所有座位，结果才计入评分。[在线玩法](../online-play.md#rated-games)解释了评分。
