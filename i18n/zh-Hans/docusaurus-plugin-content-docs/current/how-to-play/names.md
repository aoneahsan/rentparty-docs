把游戏里特有的叫法放在一起，查起来方便。

## 棋盘上 {#on-the-board}

| Rent Party用语 | 含义 |
|---|---|
| 街道 | 同色地块组中的一张地契，可以在这里建房屋和酒店。 |
| 地契 | 证明你拥有街道、车站或水电公司的卡牌。 |
| 车站 · 水电公司 | 可购买的4个车站和2家水电公司。 |
| 起点 | 第一个角落，经过时领取工资。 |
| 监狱 · 只是路过 | 第二个角落；正常掷骰走到这里时，你只是路过。 |
| 市民广场 | 休息角落，也是存钱罐自定义规则所在的位置。 |
| 前往监狱 | 第四个角落，会把你送进监狱。 |
| 城市税 · 派对税 | 两个税务格。 |
| 好运卡 · 邻里信箱 | 两套事件卡牌。 |
| 出狱通行证 | 帮你离开监狱的卡牌，可以留着或拿去交易。 |
| 游戏现金 | 每局游戏中使用的纸币。 |
| 游戏币 | 通过在线和电脑对局赚取，也可在网站购买游戏币包。可以用来购买棋子、棋盘和骰子外观，参加游戏币棋桌，或送给其他玩家。只能在游戏中使用，没有现金价值，且与游戏现金分开。[游戏币](../coins.md)有详细说明。 |
| Kettleford | 游戏自带的棋盘。 |

## 游戏内外 {#around-the-game}

| Rent Party用语 | 含义 |
|---|---|
| 电脑角色 | 有名字、有性格的电脑对手。[认识他们](./cpu-characters.md)。 |
| 游戏邀请 | 邀请朋友加入房间：链接、二维码或六位房间代码。 |
| 家庭套餐邀请 | 通过邮件邀请别人加入家庭套餐。 |
| 好友邀请 | 邀请别人加入Rent Party。确认成功后可以获得游戏币、徽章和[Pro套餐月份](../plans-and-pricing.md#friend-invites)。 |
