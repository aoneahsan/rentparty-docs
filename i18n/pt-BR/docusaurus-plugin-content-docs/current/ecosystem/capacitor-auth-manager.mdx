Um único caminho para entrar com Google nas diferentes telas por onde o jogo passa.

## O que Capacitor Auth Manager faz? \{#capacitor-auth-manager-fact-1}

O Capacitor Auth Manager oferece uma única chamada de login com Google para web, Android e iOS.

## O que mais Capacitor Auth Manager faz? \{#capacitor-auth-manager-fact-2}

Não exige o Firebase como dependência.
