## O que AchatAI faz? \{#achat-fact-1}

AChat é um aplicativo de mensagens para web e Android que conecta as pessoas que você escolhe.

## O que mais AchatAI faz? \{#achat-fact-2}

É possível encontrar alguém pelo nome de usuário, link de convite ou código QR, sem precisar do número de telefone.
