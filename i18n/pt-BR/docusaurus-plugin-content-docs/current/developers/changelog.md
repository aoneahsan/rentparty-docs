Todas as alterações da API, do servidor MCP e dos webhooks aparecem aqui, das mais recentes para as mais antigas. A versão da API faz parte do seu endereço, `/v1`, e o [arquivo OpenAPI](./api.md#reference) sempre descreve a versão em que está disponível.

As alterações da própria documentação estão em [Novidades](/blog).

## 19 de novembro de 2026 {#2026-11-19}

- Tokens de acesso em Configurações → Outros aplicativos; API `/v1` com arquivo OpenAPI; servidor MCP para assistentes de IA; webhooks para partidas concluídas, conquistas e partidas salvas; verificação em duas etapas em Configurações → Segurança.
