交換の途中でルールに迷ったときや、昨夜のゲームを振り返りたいときに使うのがRent PartyのAI機能です。それぞれボタンを押すか、スイッチをオンにしたときだけ動きます。使わなくてもゲームの遊び方は同じです。

CPUキャラクターは、設定にかかわらずゲームのルールに従ってプレイします。新しい発言で変わるのは言葉だけで、プレイの仕方は変わりません。

## どんなAI機能がありますか？ {#overview}

5つあります。ヘルプアシスタント、ゲームの振り返り、取引分析、新しいテーブルトークの発言、音声録音です。どれもあなたの操作を待ってから動きます。

| 機能 | 使う場所 | 得られるもの |
|---|---|---|
| ヘルプアシスタント | ゲームの[ヘルプページ](https://rentparty.aoneahsan.com/help)の**質問する**、またはゲームの一時停止メニュー | このドキュメントとヘルプページをもとにした回答と、参照ページ |
| ゲームの振り返り | 終了したオンラインゲームの結果とリプレイにある**振り返りを書く** | 参加者全員が読める、ゲームの短い物語 |
| 取引分析 | ゲームの交換画面にある**この交換を分析** | 色のセット、家賃、bucksへの影響と短い助言 |
| 新しいテーブルトーク | 設定の**ゲームごとに新しい発言** | そのゲーム向けに書かれたCPUキャラクターの発言 |
| 音声録音 | ヘルプページの**音声で質問**、スマートフォンのマイクボタン、交換画面の**声で提案** | 質問、チームへのメッセージ、交換の提案。送る前に確認できます |

## ヘルプアシスタントはどう動きますか？ {#help-assistant}

Rent Partyのドキュメントとゲームのヘルプページだけをもとに答えます。回答の下の**参照したページ**から元の説明を開いて確認できます。回答が間違うこともあるので、最終的には参照先のページを確認してください。

ヘルプページの**質問する**を選ぶか、ゲームの一時停止メニューから開きます。文字で質問するか、「Jailから出るには？」のような例を選べます。テーブルの向かいにいる友達に聞くように書いてください。

答えが載っているページがない場合は、その旨を伝えて**チームにメッセージ**を提案します。この場合は今日の質問回数に含まれません。[チームへの連絡方法](./help.md#write-to-the-team)もご覧ください。

## ゲームの振り返りはどう動きますか？ {#recaps}

終了したオンラインゲームの勝者、ラウンド数、接戦だったかを短い物語にします。参加したゲームの結果画面とリプレイの最初のカードのすぐ下にある**ゲームの振り返り**で、**振り返りを書く**を選びます。

ゲームの動きから一度だけ書かれ、同じテーブルの参加者は全員同じ文章を読みます。月ごとの利用枠を使うのは作成した人だけです。完成済みの文章を読むのは無料なので、急いで作成する必要はありません。再戦前に読み直すこともできます。

振り返りがあるのはオンラインゲームだけです。1台で遊んだゲームとゲストにはありません。文章はゲームと一緒に保存されます。

## 取引分析はどう動きますか？ {#trade-read}

交換画面で提案を作り、**この交換を分析**を選びます。ゲームが次の事実を計算します。

- どちらが色のセットを完成させ、または崩すか
- 移る権利書にかかる家賃
- 交換後に双方が持つbucks

文章サービスがその事実を短い助言にまとめます。たとえば「この交換でMayaは色のセットを完成させます。建物がなくても、その通りの家賃は倍になります。bucksを増やしてもらうか、その権利書を残すことを考えてください」といった内容です。

助言であって、決定するのはあなたです。分析を読まなくても提案は送れます。空の交換では分析できないので、少なくとも片方に何か入れてください。

## テーブルトークはどう動きますか？ {#table-talk}

CPUキャラクターは、購入、家賃の支払い、交換、Jail行きなどが起きると話します。Beaの通りに止まると、「私の通りに止まったの？　うれしいわ」と聞こえるかもしれません。

設定の「見た目」には、話し方を決める3つのスイッチがあります。

| スイッチ | 初期状態 | 動作 |
|---|---|---|
| CPUキャラクターの声を出す | オン | ブラウザーまたはスマートフォンの音声が発言を読み上げます。キャラクターごとに高さと速さが違います。 |
| 発言を表示する | オン | キャラクターの席の近くに約3秒間吹き出しが出ます。 |
| ゲームごとに新しい発言 | オフ | 文章サービスがそのゲーム向けの発言を書きます。オフなら端末内にある各キャラクターの既存の発言を使います。 |

最初の2つをオフにすると、CPUキャラクターは静かに遊びます。ゲーム中にも一時停止メニューの**CPUの声**から読み上げを止められます。サインイン中は設定が別の端末にも引き継がれます。端末に音声機能がない場合は、無音の吹き出しだけが表示されます。

初めて端末でCPUキャラクターと遊ぶと、テーブルの横に新しい発言を提案する小さなカードが表示されます。**オンにする**または**今はしない**を選べます。後から設定で変更できます。新しい発言にはゲームごとの利用枠があり、1台で回して遊ぶゲームとCPUゲームでは日ごとに数えます。使い切ると既存の発言に戻ります。

6人の対戦相手は[CPUキャラクター](./how-to-play/cpu-characters.md)で紹介しています。

## 音声録音はどう使いますか？ {#voice}

文字を打つ代わりに話せます。ゲームのヘルプページでは**音声で質問**、スマートフォンではホーム、ゲーム一覧、ヘルプの右下にある丸いマイクボタン、交換画面では**声で提案**を選びます。

**開始**を押し、最長2分間話せます。初回は端末またはブラウザーがマイクの許可を求めます。Rent Partyが聞くのは画面に**録音中**と表示されている間だけで、止めるとマイクを解放します。

**止めて確認**を選ぶと、録音は次のいずれかになります。

- ヘルプアシスタントへの質問
- 件名付きのチームへのメッセージ。ゲストは返事を受け取るメールアドレスも入力します。
- 交換画面で確認・編集できる取引の提案

ボタンを押して送信するまで、何も送られません。

マイクが使えない場合や録音に失敗した場合は、**文字で入力**から入力画面へ進めます。

## 音声録音は残りますか？ {#voice-kept}

長くは残りません。**聞き取った内容**の下の**この録音を削除**を選べばすぐに消せます。それ以外でも、録音、聞き取った言葉、変換後の内容は24時間以内に削除されます。ほかのプレイヤーが録音を聞いたり、言葉を見たりすることはありません。[録音の取り扱い](https://rentparty.aoneahsan.com/privacy#voice-recordings)もご覧ください。

## 各機能は何を送信しますか？ {#what-is-sent}

機能に必要な情報だけを、あなたが使ったときに送ります。送信するのは端末ではなくサーバーなので、あなたの名前、メールアドレス、アカウントの内部IDは含めません。

- **ヘルプアシスタント：** 質問と、関連するドキュメントページの文章。
- **ゲームの振り返り：** 各席の順位、純資産、支払った家賃と受け取った家賃などの結果。席は「プレイヤー1」「プレイヤー2」またはCPUキャラクター名で示し、表示名は送りません。
- **取引分析：** 取引内容と、双方の交換前後のbucks。サイコロやカードの山の情報は送りません。
- **新しい発言：** キャラクター名と短い設定、各場面の出来事と席。金額やプレイヤー名は含めません。
- **音声録音：** 音声は文字起こしサービスへ送ります。そのサービスが聞き取った内容、ブラウザーが聞き取った内容、録音したページは文章サービスへ送ります。ウェブサイトで発話中に文字が表示される場合、ブラウザー自身の音声サービスにも音声が届きます。Androidアプリでは使いません。

削除までの間、録音はメール・ファイルサービス内の非公開ファイルとして保管されます。発言の読み上げには端末内の音声だけを使い、読み上げのための送信はありません。端末に音声機能がなければ、無音の吹き出しを表示します。

質問、回答、取引分析の内容は保存しません。ゲームの振り返りはゲームと一緒に残ります。送信先と内容はプライバシーページの[AI機能は何をどこに送るか](https://rentparty.aoneahsan.com/privacy#ai-features)に詳しく記載しています。[プライバシーと利用規約](./privacy-and-terms.md#privacy)にも概要があります。

## AIのレベルとは？ {#levels}

Spark、Pulse、Surgeの3段階で、ヘルプの回答、ゲームの振り返り、取引分析にかける処理量が変わります。Sparkは素早く、Pulseはより深く、Surgeは最も深く扱います。

| プラン | AIのレベル |
|---|---|
| ゲストまたはFree | Spark |
| Pro | Pulse。料金ページに示された有料月数を連続で満たすとSurge |
| Family | Surge |

ProからSurgeへ進む月数には、支払った月だけが数えられます。フレンド招待で得た月は含まれません。有料期間が途切れると数え直しになりますが、短い間隔なら連続とみなされます。現在の状態は[プランページ](https://rentparty.aoneahsan.com/plan)で確認できます。

レベルはプランで使える最高段階です。AIの利用枠が混み合うと、一時的に低い段階で動く場合があります。プラン自体については[プランと料金](./plans-and-pricing.md#ai-level)をご覧ください。

## 各機能はどれくらい使えますか？ {#allowances}

すべてのプランに各機能の利用枠があり、ProとFamilyでは増えます。現在の数値は[料金ページ](https://rentparty.aoneahsan.com/pricing)、使用済みの数はプランページで確認できます。

| 機能 | 数える期間 |
|---|---|
| ヘルプアシスタントへの質問 | 1日 |
| ゲームの振り返り | 1か月 |
| 取引分析 | 1日 |
| 新しいテーブルトークの発言 | 1ゲーム（1台で回して遊ぶゲームとCPUゲームでは1日） |
| 音声録音 | 1か月 |

日と月はUTCで区切るため、新しい質問枠があなたの深夜以外に始まることもあります。画面に時刻が表示されます。

枠を使い切ると、その機能は翌日、翌月、または次のゲームまで待ちます。ほかの機能は使い続けられます。ドキュメントを読めますし、交換の提案は送れ、文字入力もできます。ドキュメントに答えがない質問や、何も返らなかったリクエストは数えません。

## ゲストも使えますか？ {#guests}

はい。振り返り以外をSparkで使えます。ゲストの利用枠はFreeプランの数値をもとに決まり、毎日新しくなります。各画面に今日の残数が表示されます。

各リクエストの前に、人による操作か簡単に確認します。保存される情報は[ゲストがAIを使う場合の取り扱い](https://rentparty.aoneahsan.com/privacy#guests-and-ai)をご覧ください。

## AIが休止中はどうなりますか？ {#resting}

AI機能は無料のAI利用枠で動いています。使い切ると休止し、その間に料金は発生しません。各画面に再開時刻が表示されます。ゲームはそのまま続きます。

- ヘルプアシスタントはドキュメントとチームを案内します。
- ゲームの動きは保存されるので、振り返りは後から作成できます。
- 取引分析がなくても交換の提案を送れます。
- 音声録音を待つ間は文字で入力できます。
- CPUキャラクターは既存の発言を使います。

## CPUの声を止めるには？ {#settings}

静かにしたい場合は、設定の「見た目」にある**CPUキャラクターの声を出す**か、一時停止メニューの**CPUの声**をオフにしてください。テーブルトークのほかの2つのスイッチも設定にあります。ヘルプアシスタント、振り返り、取引分析、音声にはオフにするスイッチがありません。どれもボタンを押したときだけ動きます。

マイクを使わせない場合は端末やブラウザーのRent Partyの権限をオフにしてください。[権限ページ](https://rentparty.aoneahsan.com/permissions#microphone)に使用タイミングがあります。

今、聞きたいことがあるなら[ヘルプアシスタントに質問](https://rentparty.aoneahsan.com/help?help=open)できます。
