Rent Partyで使う言葉をまとめました。

## ボード上の言葉 {#on-the-board}

| 用語 | 意味 |
|---|---|
| 通り | 色のセットに属する権利書。家やホテルを建てられます。 |
| 権利書 | 通り、駅、公共施設の所有を示すカード。 |
| 駅・公共施設 | 所有できる4つの駅と2つの公共施設。 |
| Start | 最初の角。通過時に給与を受け取ります。 |
| Jail・通過するだけ | 2つ目の角。通常のサイコロで止まったときは「通過するだけ」です。 |
| Town Square | 休憩する角。貯金箱のハウスルールが使われる場所です。 |
| Go to jail | 4つ目の角。Jailへ送られます。 |
| City tax・Party tax | 2つの税金マス。 |
| Lucky Break・Neighborhood Mail | 2種類のカードの山。 |
| Jail pass | Jailから出られるカード。持っておくことも交換することもできます。 |
| bucks | 各ゲームで使うお金。 |
| coins | オンラインゲームやCPUゲームで獲得するか、ウェブサイトでコインパックを購入して入手します。コマ、ボード、サイコロの見た目に使い、コインテーブルに持ち込んだり、ほかのプレイヤーに送ったりできます。アプリ内だけで使え、現金価値はなく、bucksとは別です。詳しくは[コイン](../coins.md)をご覧ください。 |
| Kettleford | ゲームに最初から付いてくるボード。 |

## ゲームの周辺で使う言葉 {#around-the-game}

| 用語 | 意味 |
|---|---|
| CPUキャラクター | 名前と個性を持つコンピューター対戦相手。[キャラクター紹介](./cpu-characters.md)をご覧ください。 |
| ゲームへの招待 | リンク、QRコード、または6文字のルームコードでゲームルームに招待します。 |
| Familyへの招待 | Familyプランの席への招待。メールで届きます。 |
| フレンドの招待 | Rent Party自体への招待。確認された招待で、コイン、バッジ、[Proの利用期間](../plans-and-pricing.md#friend-invites)を獲得できます。 |
