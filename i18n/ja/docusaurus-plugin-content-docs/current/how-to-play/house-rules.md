ゲーム開始前にプリセットを選ぶか、ハウスルールを1つずつ切り替えます。[ゲームを始める](../intro.md#start-a-game)ときのハウスルール設定で選べます。

:::note[このページの数値]

現在のゲーム設定に合わせています。最新の設定は、ゲーム内の[遊び方](https://rentparty.aoneahsan.com/how-to-play)で確認できます。

:::

## 選べるプリセットは？ {#presets}

| プリセット | 内容 |
|---|---|
| 公式 | 基本ルール。ハウスルールはすべてオフです。 |
| ファミリークラシック | 貯金箱、Startにぴったり止まったときのボーナス、いつでも交換できるルールが有効です。 |
| クイック | [勝利条件](./rules.md#winning)で説明する短いゲームです。 |
| トーナメント | 公式ルールに、手番と選択の制限時間を常時適用します。 |

## 切り替えられるハウスルールは？ {#house-rules}

| ルール | 内容 |
|---|---|
| 貯金箱 | 税金、手数料、カードによる銀行への支払いをすべて貯めます。修理代も含みます。Town Squareに止まった人が全額を受け取ります。 |
| Start到着ボーナス | Startにぴったり止まると、さらに200 bucksを受け取ります。 |
| 自分の手番だけ交換 | 交換できるのは自分の手番だけです。 |
| ゲームの長さ制限 | 決めたラウンド数または分数で終了し、純資産が最も多い人が勝ちます。 |
| 競売なし | 誰も買わなかった通りは銀行に残ります。 |
| 開始時のお金と給与 | 金額を自分で設定できます。 |
| City taxの選択 | City taxに止まったら、200 bucksか純資産の10％を支払います。計算する前にどちらかを選びます。 |
| 秘密入札 | ライブゲームとローカルゲームで使えます。[競売の説明](./rules.md#auctions)をご覧ください。1台の端末で遊ぶ場合は、端末を回しながら各自が入札額を秘密で入力します。 |
| クイック取引 | 全員が銀行からランダムに選ばれた権利書2枚を持って始めます。 |
| 刑期満了 | Jailでゾロ目を3回連続で出せなければ、罰金なしで出られます。 |

家族でいつも税金をボードの真ん中に積み、休憩マスに止まった人が全部もらっていたなら、それが貯金箱ルールです。

## レーティング対象のゲームで使えるルールは？ {#rated-games}

公式またはトーナメントのみです。オンラインゲームで全席が人間のときにレーティングへ反映されます。詳しくは[オンライン対戦](../online-play.md#rated-games)をご覧ください。
