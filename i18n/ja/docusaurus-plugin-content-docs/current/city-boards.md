テーブルを新しい都市へ。通りやカードにはその街の名前が付きますが、ルールは同じ。コインで変わるのは見た目だけです。

## 都市セットには何が入っていますか？ {#city-set}

各都市には、通りの名前、権利書カード、カードの裏面、紙幣、アバター、サイコロ、コマの7種類の見た目があります。1つずつ購入しても、セットをそろえても、ルールや運は変わりません。

| 見た目 | 変わるところ | 見える人 |
|---|---|---|
| 通りの名前 | 通り、駅、カードにその都市の名前が付きます。家賃とルールは同じです。 | あなたがホストのときは全員 |
| 権利書カード | 権利書に街路標識の帯とランドマークの透かしが入ります。 | あなたの画面 |
| カードの裏面 | 都市のランドマークが裏面に入ります。表は変わりません。 | あなたの画面 |
| 紙幣 | 国の通貨コードと記号、都市のランドマークをあしらった紙幣になります。額面は同じです。 | あなたの画面 |
| アバター | 都市のフレームとランドマークのバッジが付きます。 | テーブルの全員 |
| サイコロ | 都市の色になり、1の面にランドマークが入ります。出目の公平さは同じです。 | テーブルの全員 |
| コマ | ボード上のコマに都市の印が付きます。 | テーブルの全員 |

オンラインのテーブル全体で使う都市はホストが選びます。通りとカードは全員に表示されます。

セットを完成させるときは、まだ持っていない見た目の分だけ支払います。
