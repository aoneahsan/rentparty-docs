コインはRent Partyの中だけで使えます。現金価値はなく、お金と交換できません。

プレイで獲得でき、ウェブサイトではコインパックも購入できます。[ショップ](https://rentparty.aoneahsan.com/shop)で見た目を買ったり、コインテーブルに参加したり、ほかのプレイヤーへ送ったりできます。

:::note[このページの数値]

現在のゲーム設定に合わせています。最新の数値はゲーム内の各ページをご覧ください。パックはショップ、テーブルはコインテーブル、送金はコイン送金で確認できます。

:::

## コインはどうやって得られますか？ {#earning}

オンラインゲームの完走、サインイン中のCPUゲーム、バッジ、デイリーチャレンジ、歓迎コイン、確認済みのフレンド招待で獲得します。ショップの**コインの獲得方法**に一覧があります。

ウェブサイトでは[コインパック](#coin-packs)も購入できます。入出金はすべてコイン履歴に残ります。

## コインパックはどう使いますか？ {#coin-packs}

コインパックを購入できるのはウェブサイトだけです。Googleでサインインし、[ショップ](https://rentparty.aoneahsan.com/shop)の**コインパック**を選んでください。Androidアプリにはありません。

| パック | コイン |
|---|---|
| $5 | 1,000コイン |
| $10 | 2,000コイン |
| $15 | 3,000コイン |
| $20 | 4,000コイン |
| $50 | 10,000コイン |
| $100 | 20,000コイン |

**金額を指定**することもできます。$21以上の整数ドルを選ぶと、1ドルあたり200コインです。次へ進む前にショップにコイン数が表示されます。

決済はパートナーのページで行います。完了すると、まもなくコイン履歴に反映されます。

コインパックについては[利用規約](https://rentparty.aoneahsan.com/terms)もご覧ください。

## コインテーブルはどう使いますか？ {#coin-tables}

参加者全員が同じ参加費を出し、最後まで残った人がテーブルのコインを受け取ります。

[コインテーブル](https://rentparty.aoneahsan.com/coin-tables)から選んでください。参加費は50〜1,000コインです。各カードに参加費、席数、現在の参加希望者、集まるコイン数、必要な評判レベルがあればそのレベルが表示されます。

1. カードの**参加する**を選び、**コインを出す**で参加費を確認します。
2. ゲーム開始時に残高から引かれます。待機中には確保されません。
3. 開始前に退出すれば、コインは引かれません。

参加費を払えるコインが必要です。同時に座れるテーブルは1つです。

コインテーブルの結果はレーティングと[評判](./reputation.md)に反映されます。

## 参加費はどう分配されますか？ {#settling}

| 起きたこと | コインの行き先 |
|---|---|
| 1人だけが最後まで残る | 全員が出した参加費を受け取ります。 |
| 時間・ラウンドの制限または合意により、純資産で決着する | 純資産が最高で並んだ席が分け合います。割り切れない分は、終了順位の順に1コインずつ配ります。 |
| 最初のサイコロの後に退出、または長くオフラインになる | 参加費はテーブルに残ります。 |
| 最初のサイコロの前にゲームが中止される | 全員に参加費が返ります。 |
| コインを受け取れる人がいない | 全員に参加費が返ります。 |

ライブゲームと同じ[2分間のオフラインルール](./online-play.md#offline)が適用されます。

## コイン対戦はどう使いますか？ {#coin-challenges}

フレンドと遊ぶコインテーブルです。全員が同じ参加費を出し、最後まで残った人が受け取ります。

[コインテーブル](https://rentparty.aoneahsan.com/coin-tables)の**コイン対戦**から進みます。

1. 参加費と招待する人を選びます。自分を含めて最大8人で、テーブルに集まるコイン数が表示されます。
2. **対戦を申し込む**を選びます。フレンドは**コインを出す**か**今回は参加しない**を選びます。
3. 招待した全員が返事をしたら**テーブルを開く**を選びます。ゲーム開始時に各人の参加費が引かれます。

誰もサイコロを振る前なら**中止**でき、出したコインはそれぞれ返ります。

[オンライン中](./online-now.md#challenge)から1人のフレンドに申し込んだり、コインテーブルの相手を探したりもできます。

## コインを送るには？ {#sending}

[コインを送る](https://rentparty.aoneahsan.com/coins/send)から、Rent Partyのほかの利用者へ送れます。

1. 相手の名前の最初の3文字、または招待コード全体を入力し、**検索**を選びます。
2. 10、20、30のように10コイン単位で金額を選びます。
3. **確認**してから**送る**を選びます。

| ルール | 内容 |
|---|---|
| 送金手数料 | 送る額の10％です。100コインを送ると相手に90コイン届きます。 |
| 1日の上限 | 送信・受信とも1日10,000コインまで。UTCの深夜に計数がリセットされます。 |
| 確認方法 | 送金PIN、または最後のサインインから15分以上経っている場合の再サインイン。直近にサインインしていれば、その回はPIN不要です。 |

送ったコインは取り消せません。双方のコイン履歴に表示されます。

お互いのどちらかがブロックしている場合や、あなたのアカウントが停止中の場合は送れません。

## 送金PINを設定するには？ {#pin}

[設定](https://rentparty.aoneahsan.com/settings)の**オンラインとコイン**で**PINを設定**を選びます。4〜6桁を使い、誕生日は避けてください。直近にサインインしていなければ、先に再サインインします。

PINはコイン送金のたびに確認します。間違いが続くとしばらくロックされますが、再サインインでも送金を確認できます。同じ場所から変更・削除できます。PINがない場合は再サインインが必要です。
