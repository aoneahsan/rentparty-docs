## AchatAI は何をする？ \{#achat-fact-1}

AChat は、選んだ相手とウェブや Android でやり取りできるメッセージアプリです。

## AchatAI ではほかに何ができる？ \{#achat-fact-2}

電話番号なしで、ユーザー名、招待リンク、QR コードから相手を見つけられます。
