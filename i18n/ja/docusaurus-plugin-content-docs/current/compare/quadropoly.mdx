Quadropoly は Android で八段階の AI と対戦する一人遊び中心のゲームです。Rent Party の CPU キャラクターは初級から達人まで四段階。それぞれ名前と性格があります。友達とも、プライベートルームや一台のスマートフォンで遊べます。

Rent Party は Android のブラウザーと [Google Play](https://play.google.com/store/apps/details?id=com.aoneahsan.rentparty) で遊べます。

## Quadropoly の進行状況は？ \{#move}

Quadropoly に残ります。こちらから読み取ることはできません。

## 一人で始め、友達を呼ぶ \{#table}

1. [ゲームを始める](https://rentparty.aoneahsan.com/play)を開き、CPU キャラクターを選びます。接続は必要ですが、アカウントは不要です。
2. [対戦相手の強さ](../how-to-play/cpu-characters.md)を初級・普通・上級・達人から選びます。
3. 友達と勝負したくなったら[ルームを作り](../online-play.md#start-a-room)、招待を送ります。

## 一人で遊ぶなら Quadropoly も \{#stay}

八段階の AI、数百の独自ルール、上位プレイヤーのリプレイから学びたい Android の一人遊びには、Quadropoly が向いています。
