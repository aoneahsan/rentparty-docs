Board Game Arena をやめる必要はありません。そこには何百ものゲームがあり、Rent Party は一つだけ。物件を売買する夜はこちらへ、ほかのゲームのアカウントはそのまま使ってください。

こちらではプランに関係なくテーブルを開けます。一台を囲む持ち回りプレイ、CPU 対戦、オンラインルームもあります。

## Premium と対戦履歴は？ \{#move}

どちらも Board Game Arena に残ります。

## いつものように手番で遊ぶ \{#table}

1. [ゲームを始める](https://rentparty.aoneahsan.com/play)で Google ログインし、オンラインを選びます。
2. 「数日かけて」を選び、[手番ごとの期限](../online-play.md#modes)を 8、12、24、48 時間から設定します。
3. [招待](../online-play.md#invites)を送ります。プランを問わずテーブルは開けますが、[プランの上限](../plans-and-pricing.md#limits)で同時に進められる数は変わります。

## 毎週違うゲームで遊ぶなら \{#stay}

Board Game Arena が向いています。何百ものゲームで、リアルタイムと手番制の卓を選べます。

## 両ゲームの現状 \{#facts}

Board Game Arena は、一台で遊ぶ Premium のホットシートモードを案内しています。コンピュータープレイヤー、一時停止、集められる見た目、ボード作成、Android・iOS アプリ、第三者広告は、確認したページに記載がないため表から除いています。
