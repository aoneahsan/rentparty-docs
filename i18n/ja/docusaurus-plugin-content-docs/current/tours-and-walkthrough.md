Rent Partyには、ページごとのツアーと、ゲーム全体を6画面で紹介する[Rent Partyの遊び方](https://rentparty.aoneahsan.com/how-rent-party-works)があります。後者は約1分で見られ、途中でいつでも閉じられます。

## ページツアーを始めるには？ {#page-tour}

ヘッダーの**このページのツアーを見る**を押してください。スマートフォンでは画面上部のバーにあります。ツアーのあるページを初めて開くと、「初めてですか？　このページを簡単に案内します」という短い案内がボタンを指します。**見てみる**で開始、**閉じる**で案内を消せます。案内はページごとに一度だけ表示されます。

## どのページにツアーがありますか？ {#pages}

| ページ | 案内する内容 |
|---|---|
| [ホーム](https://rentparty.aoneahsan.com/) | どのゲームも一時停止できること、遊び方、ゲーム会の流れ、対戦相手 |
| [プレイ](https://rentparty.aoneahsan.com/play) | 遊び方の選択、1台で回して遊ぶ方法、ルームへの参加、Rent Partyのインストール |
| [ゲーム](https://rentparty.aoneahsan.com/games) | 始めたゲームを遊び方ごとに整理した一覧 |
| [オンラインで遊ぶ](https://rentparty.aoneahsan.com/online) | ルームの作成、コードでの参加、公開ルーム |
| [ショップ](https://rentparty.aoneahsan.com/shop) | プレイで得たコインで買えるコマ、ボード、サイコロ、フレーム |
| [ランキング](https://rentparty.aoneahsan.com/leaderboard) | 自分の順位とレーティングの仕組み |
| [プロフィール](https://rentparty.aoneahsan.com/profile) | テーブルでの名前、装備中の見た目、プレイ記録 |
| [設定](https://rentparty.aoneahsan.com/settings) | アカウント、お知らせ、見た目、データ |

## 手順を飛ばしたり、途中で閉じたりできますか？ {#controls}

はい、いつでもできます。**次へ**と**戻る**で1手順ずつ移動し、**すべての手順**から直接選ぶこともできます。**ツアーをスキップ**、**ツアーを閉じる**、Escapeキー、暗くなったページのタップで終了します。キーボードでは矢印キーで移動できます。スマートフォンでは各手順が画面下部のカードとして開きます。

## 「Rent Partyの遊び方」とは？ {#walkthrough}

ゲームの流れを6画面で紹介します。

1. **今夜の遊び方を選ぶ：** フレンドとオンライン、1台を回して遊ぶ、名前も個性もあるCPUキャラクターと対戦。
2. **振る、買う、建てる：** 不動産を交換しながら遊ぶルールをゲームが処理します。銀行役は不要です。
3. **テーブルで交渉する：** 権利書、bucks、またはその両方を相手に提案できます。
4. **いつでも一時停止：** 用事ができたら止めて、数日後に続きから遊べます。
5. **仲間をオンラインに集める：** リンク、QRコード、6文字のルームコードで招待します。
6. **ゲームを飾る：** コインで変わるのは見た目だけ。運は変わりません。

サイトのフッターまたはアカウントメニューの**Rent Partyの遊び方**から開けます。初回案内の最後にも「Rent Partyは初めてですか？　遊び方を見る」と表示されます。

準備ができたら、[ゲームを始めましょう](https://rentparty.aoneahsan.com/play)。
