誰でも[ライセンス確認ページ](https://rentparty.aoneahsan.com/verify-license)でホワイトラベル版Rent Partyを確認できます。検証はライセンスサービスが行います。

## キーで確認するには？ {#by-key}

ライセンスキーを入力してください。キーは`RENTPARTY-WL-`で始まります。結果には、有効・設定中・取り消しの状態と、ライセンス保持者、ドメイン、プラットフォーム、更新期間の終了日など公開情報が表示されます。メールアドレスや価格は表示されません。

## ドメインで確認するには？ {#by-domain}

`play.yourbrand.com`のようにドメインを入力してください。ライセンスを受けた運用サイトは`/.well-known/rentparty-white-label-license.json`にライセンスファイルを公開します。確認ページはそのファイルと、そこに記載されたライセンスを読み取ります。

## 結果の意味は？ {#answers}

| 結果 | 意味 |
|---|---|
| 有効 | ライセンスは有効です。 |
| 設定中 | ライセンスは発行済みで、運用サイトはまだ公開されていません。 |
| 取り消し | 条件外での使用によりライセンスが終了しました。 |
| 対象外のドメイン | ライセンスファイルはありますが、そのドメインはライセンスの対象外です。 |
| ライセンスファイルなし | ドメインにRent Partyのライセンスファイルがありません。 |
