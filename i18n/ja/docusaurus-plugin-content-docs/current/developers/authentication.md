アクセストークンは、コードが各リクエストの`Authorization: Bearer <token>`に入れる長い秘密情報です。**設定 → その他のアプリ**で作成し、読める範囲と有効期限を選び、いつでも取り消せます。連携アプリは代わりにOAuthを使うので、トークンを渡す必要はありません。

## トークンを作るには？ {#make-a-token}

1. **設定 → その他のアプリ → アクセストークン**を開き、**新しいトークン**を選びます。
2. 後で分かる名前を付けます。「ゲーム会の一覧表」のほうが「トークン1」より見つけやすいでしょう。
3. 権限と有効期間を選びます。
4. トークンが一度だけ表示されます。パネルを閉じる前にコピーして安全に保管してください。

一覧には名前、権限、先頭の数文字、作成日時、最終使用日時が表示されます。全文は表示されません。作成のたびにメールが届くため、心当たりのないトークンにも気付けます。

## トークンを再表示できますか？ {#reveal}

はい、**サインインから10分以内**なら可能です。行の**表示**を選んでください。

| 状況 | 動作 |
|---|---|
| サインインから10分以内 | トークンが表示されます。 |
| 10分以上経過 | **再度サインイン**が提案され、同じ行へ戻ります。 |
| 2段階認証がオン | 10分以内でも認証アプリのコードが必要です。 |

何週間もサインインしたままにできるのは便利ですが、借りた端末からも同じように見えます。新しいサインインで本人の操作を確かめます。再表示は1時間に10回までで、毎回アカウントに記録されます。トークン全文をメールで送ることはありません。

## 権限には何がありますか？ {#scopes}

各記録に読み取り権限があります。保存したゲームには削除権限もあります。

| 権限 | トークンでできること |
|---|---|
| `<part>:read` | プロフィールと統計、終了したゲームの結果、バッジとレーティング履歴、または保存したゲームを読む |
| `saved_games:delete` | 自分が保存したゲーム1件を削除する |

ゲーム、プロフィール、結果を書き換える権限はありません。正確な権限名は[OpenAPIファイル](./api.md#reference)にあります。

**削除は別の許可です。** 保存ゲームを読む権限だけでは削除できません。削除権限は画面でも分かれており、初期状態ではオフです。作成済みトークンの権限は増やせません。追加が必要なら新しいトークンを作り、古いものを取り消してください。チームの管理権限を持つトークンは作れません。

## トークンの有効期間は？ {#expiry}

**30、90、365日**から選べます。失効の7日前にメールが届きます。期限後のリクエストには`401`が返ります。

## 再発行や取り消しは？ {#rotate-and-revoke}

- **再発行**で新しいトークンを作れます。古いものはコードの差し替えのため24時間使え、その後取り消されます。両方ともそれまでは一覧に表示されます。
- **取り消す**とすぐに無効になり、次のリクエストには`401`が返ります。確認のため2回押します。ダイアログはありません。

Rent Partyアカウントを削除すると、すべてのトークン、連携アプリ、Webhookも取り消されます。

## トークンなしでアプリを連携するには？ {#oauth}

AIアシスタントと同じOAuth 2.1を使います。アプリは`https://rentparty.aoneahsan.com/oauth/consent`にあるRent Partyの同意画面へ送ります。画面には次が表示されます。

- アプリ名と戻り先アドレス
- アクセス対象のRent Partyアカウント
- 要求する権限の平易な説明。読み取りと削除は別のチェックボックスで、削除は初期状態でオフ
- 並んだ**承認**と**拒否**のボタン

2段階認証がオンなら、承認時にコードが必要です。連携後は**設定 → その他のアプリ → 連携アプリ**に表示され、名前変更や取り消しができます。取り消すと次のリクエストからアクセスできなくなります。[AIアシスタント](./mcp.md#consent)もご覧ください。

## リクエストは何回まで送れますか？ {#rate-limits}

トークンと連携アプリごとに**1分あたり120件**です。アカウント全体にはプランに応じた1日あたりの上限もあります。すべてのトークンとアプリで共有するため、トークンを増やしても上限は増えません。設定の「その他のアプリ」に、プランの上限と今日の使用数が表示されます。

応答には3つのヘッダーが含まれます。

| ヘッダー | 意味 |
|---|---|
| `RateLimit-Limit` | この期間に許可されるリクエスト数 |
| `RateLimit-Remaining` | 残りのリクエスト数 |
| `RateLimit-Reset` | 次の期間までの秒数 |

超過すると`Retry-After`ヘッダー付きの`429`が返ります。指定の秒数を待ってやり直してください。

大量のリクエストを同時に送ると、Rent Partyに届く前にホスティング基盤から`546`が返ることがあります。順番に、または少数ずつ送ってください。`546`の後は1秒待って再試行してください。

## エラーの形式は？ {#errors}

どのルートのエラーも同じ形式です。

```json
{
  "error": {
    "code": "reauth_required",
    "message": "Sign in again to see this token.",
    "details": { "max_age_seconds": 600 },
    "correlation_id": "…"
  }
}
```

プログラムでは`code`を見てください。`message`は人向けで、文言が変わる可能性があります。失敗したリクエストについて連絡する場合は`correlation_id`を添えてください。その1件を見つけるために使います。

| ステータス | 一般的な意味 |
|---|---|
| `401` | トークンがない、違う、取り消された、期限切れ |
| `403` | 必要な権限がない（`details`に表示）、または新しいサインインが必要 |
| `404` | 自分の記録にそのIDがない。ほかの人の記録も同じ扱い |
| `429` | 回数制限に達しました。`Retry-After`を確認してください |

コードの全一覧は[OpenAPIファイル](./api.md#reference)にあります。
