Rent PartyのMCPサーバーを使うと、頼んだときにAIアシスタントが自分の記録を読めます。「直近10ゲームで何回勝った？」「1か月触っていない保存ゲームは？」などと聞けます。アシスタントにアドレスを1つ渡し、Rent Partyにサインインして、同意画面で見せる範囲を選びます。Claude、ChatGPT、Claude Code、Cursorなど、MCPに対応するアシスタントで使えます。

## アドレスは？ {#address}

```text
https://bgajltrjcqnchwhewouc.supabase.co/functions/v1/mcp
```

**設定 → その他のアプリ → AIアシスタントを接続**にもコピーボタン付きで表示されます。アシスタントにトークンを貼り付ける必要はありません。このアドレスからRent Partyのサインイン先を見つけて案内します。

## 各アシスタントを接続するには？ {#connect}

アプリのメニューは更新で変わることがあります。手順と画面が違う場合は、設定の**コネクター**を探してください。

### Claude {#claude}

1. Claudeの**設定 → コネクター**でカスタムコネクターを追加します。
2. 上のアドレスを貼り付けます。
3. 求められたらRent Partyにサインインし、同意画面で承認します。

### ChatGPT {#chatgpt}

1. ChatGPTの**設定 → コネクター**を開きます。アカウントによっては最初に開発者モードが必要です。
2. 上のアドレスでコネクターを追加します。
3. 求められたらRent Partyにサインインし、同意画面で承認します。

### Claude Code {#claude-code}

```bash
claude mcp add --transport http rentparty https://bgajltrjcqnchwhewouc.supabase.co/functions/v1/mcp
```

Claude Codeで`/mcp`を実行し、**rentparty**を選びます。開いたブラウザーでサインインしてください。

### Cursor {#cursor}

`mcp.json`にRent Partyを追加します。

```json
{
  "mcpServers": {
    "rentparty": {
      "url": "https://bgajltrjcqnchwhewouc.supabase.co/functions/v1/mcp"
    }
  }
}
```

Cursorが初めて使用するときにサインインを求めます。

## 同意画面では何を確認しますか？ {#consent}

アシスタントが何かを読む前に、`https://rentparty.aoneahsan.com/oauth/consent`で次の内容が表示されます。

- **要求しているアプリ**と、処理後の戻り先アドレス
- **アクセス対象のRent Partyアカウント**。Googleアカウントを複数持っている場合は確認してください。
- **許可する操作**を平易な文で表示します。読み取りと削除は別のチェックボックスで、削除は初期状態でオフです。
- 並んだ**承認**と**拒否**のボタン

[2段階認証](./two-step-sign-in.md)がオンなら、承認時にコードが必要です。自動承認はありません。新しい連携はすべてこの画面を通ります。

アシスタントが使えるツールは、選んだ権限に限られます。読み取りだけなら削除はできません。

## 保存ゲームの削除はどう扱われますか？ {#removing}

アシスタントは削除を**準備**できますが、**実行**できるのはあなたです。古い保存データを消すよう頼むと、対象のゲームとRent Partyへのリンクが表示されます。10分以内にRent Party上で確認しなければ、保存データは残ります。

そのため、ウェブページや貼り付けた文章に隠れた指示でアシスタントが削除を提案しても、自分で確認することはできません。

同意画面で削除権限を選ばなければ、削除の準備すらできません。

## アシスタントを切断するには？ {#disconnect}

**設定 → その他のアプリ → 連携アプリ**で、その行の**取り消す**を選びます。次のリクエストからアクセスできなくなります。一覧には各アプリの権限、接続日時、最終使用日時が表示され、承認直後に新しいアプリが現れます。連携時にはメールも届きます。

## 動かない場合は？ {#troubleshooting}

| 表示される内容 | 対処法 |
|---|---|
| アシスタントに再サインインを求められる | 認証の期限が切れました。アシスタントからRent Partyに再サインインしてください。 |
| 権限が足りないと言われる | 許可されていない権限です。切断して再接続し、同意画面で選んでください。 |
| ツールからRent Partyが消えた、または全リクエストが失敗する | 連携が取り消されました。**連携アプリ**を確認し、必要なら再接続してください。 |
| 削除すると言われた保存ゲームが残っている | Rent Partyで10分以内に確認されませんでした。もう一度依頼してください。 |
| 利用状況を知りたい | **連携アプリ**に各アプリの最終使用日時が表示されます。 |
