ゲームには記録が残ります。勝利、レーティング、バッジ、まだ終わっていない保存データ。この節では、その記録をほかの場所で使う方法を説明します。ゲーム会の一覧表、グループチャットに勝者を知らせるボット、直近10ゲームを振り返るAIアシスタントなどを作れます。

方法は3つあり、どれも**設定 → その他のアプリ**から自分で有効にします。

## どれを選べばよいですか？ {#which-one}

| したいこと | 使うもの | できること | 最初に読むページ |
|---|---|---|---|
| 自分のコードで記録や結果を取得する | アクセストークンとAPI | トークンで許可した範囲の読み取り | [アクセストークン](./authentication.md)、次に[API](./api.md) |
| Claude、ChatGPT、Claude Code、Cursorにゲームについて質問する | MCPサーバー | 同意画面で許可した範囲の読み取り | [AIアシスタント](./mcp.md) |
| ゲーム終了と同時に知らせを受ける | Webhook | イベントの受信だけ | [Webhook](./webhooks.md) |

## アクセスできるものは？ {#what-it-reaches}

自分の記録だけです。

- プロフィールと統計
- 終了したゲームの結果
- バッジとレーティングの履歴
- 保存したゲーム。読み取りと、別に許可した場合の削除

これがすべてです。サイコロを振る、入札する、進行中のゲームを操作することはできません。コマを動かせるのはゲーム本体だけです。

## どの方法にも共通するルールは？ {#ground-rules}

- **あなたが開くまで閉じています。** 新しいアカウントにはトークンも連携アプリもWebhookもありません。
- **削除は別の許可です。** 読み取りと、保存ゲームの削除は異なります。削除権限は初期状態でオフです。AIアシスタントでは、Rent Party内で確認するまで何も削除できません。
- **あなたの席だけです。** 各リクエストはゲームと同じルールで、あなたとして処理されます。ほかのプレイヤーの非公開情報には届きません。
- **入口をすべて確認できます。** 設定の「その他のアプリ」に、トークン、連携アプリ、Webhookとそれぞれの最終使用日時が表示されます。

[2段階認証](./two-step-sign-in.md)をオンにすると、トークンの再表示や新しい連携の承認にコードが必要になります。
