ہمارے اپنے تمام نام ایک جگہ۔

## بورڈ پر {#on-the-board}

| Rent Party کی اصطلاح | مطلب |
|---|---|
| سڑک | ایک رنگ کے مجموعے کا ملکیتی کاغذ؛ یہاں گھر اور ہوٹل بنتے ہیں۔ |
| ملکیتی کاغذ | وہ کارڈ جو سڑک، اسٹیشن یا سہولت پر آپ کی ملکیت ثابت کرتا ہے۔ |
| اسٹیشن · سہولت | 4 اسٹیشن اور 2 سہولتیں جن کے مالک بن سکتے ہیں۔ |
| Start | پہلا کونا، جہاں تنخواہ ملتی ہے۔ |
| جیل · بس گزر رہے ہیں | دوسرا کونا، اور عام پانسے سے اس پر رکنے کی حالت۔ |
| Town Square | آرام کا کونا، گلک والا گھریلو قاعدہ یہاں کام کرتا ہے۔ |
| Go to jail | چوتھا کونا؛ یہ آپ کو جیل بھیجتا ہے۔ |
| City tax · Party tax | ٹیکس کے دو خانے۔ |
| Lucky Break · Neighborhood Mail | کارڈوں کے دو مجموعے۔ |
| جیل پاس | جیل سے نکالنے والا کارڈ؛ رکھیں یا اس کا سودا کریں۔ |
| کھیل کی رقم | ہر کھیل کی اندرونی رقم۔ |
| سکے | آن لائن اور CPU کھیلوں میں کمائے جاتے ہیں، یا ویب سائٹ پر سکے کے پیک سے لیے جاتے ہیں۔ ٹوکن، بورڈ اور پانسوں کے انداز خریدنے، سکوں والی میز میں رکھنے یا دوسرے کھلاڑی کو بھیجنے کے لیے ہیں۔ صرف ایپ کے اندر استعمال ہوتے ہیں، نقد قیمت نہیں رکھتے، اور کھیل کی رقم سے الگ ہیں۔ تفصیل [سکوں](../coins.md) میں ہے۔ |
| Kettleford | کھیل کے ساتھ ملنے والا بورڈ۔ |

## کھیل کے آس پاس {#around-the-game}

| Rent Party کی اصطلاح | مطلب |
|---|---|
| CPU کردار | نام اور مزاج والے کمپیوٹر حریف۔ [ان سے ملیں](./cpu-characters.md)۔ |
| کھیل کی دعوت | کمرے کی دعوت: لنک، QR کوڈ یا 6 حروف کا کمرہ کوڈ۔ |
| Family دعوت | Family منصوبے کی نشست کے لیے ای میل سے بھیجی گئی دعوت۔ |
| دوست کی دعوت | خود Rent Party میں آنے کی دعوت۔ تصدیق شدہ دعوتوں پر سکے، بیج اور [Pro کے مہینے](../plans-and-pricing.md#friend-invites) ملتے ہیں۔ |
