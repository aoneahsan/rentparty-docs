Rent Party کا MCP سرور، آپ کے کہنے پر، AI اسسٹنٹ کو آپ کے ریکارڈ پڑھنے دیتا ہے۔ *”اپنے آخری دس کھیلوں میں کتنے جیتے؟“* *”کون سے محفوظ کھیل میں نے ایک ماہ سے نہیں کھولے؟“* اسسٹنٹ کو ایک پتہ دیں، Rent Party میں لاگ اِن کریں، اور اجازت کے صفحے پر چنیں کہ وہ کیا دیکھ سکتا ہے۔ یہ Claude، ChatGPT، Claude Code، Cursor اور MCP سمجھنے والے دوسرے اسسٹنٹس کے ساتھ چلتا ہے۔

## پتہ کیا ہے؟ {#address}

```text
https://bgajltrjcqnchwhewouc.supabase.co/functions/v1/mcp
```

یہ **ترتیبات ← دوسری ایپس ← AI اسسٹنٹ جوڑیں** میں بھی نقل کرنے کے بٹن کے ساتھ ہے۔ آپ کسی اسسٹنٹ میں ٹوکن پیسٹ نہیں کرتے۔ وہ اس پتے سے Rent Party کا لاگ اِن ڈھونڈتا اور آپ کو وہاں لے جاتا ہے۔

## ہر اسسٹنٹ کیسے جوڑیں؟ {#connect}

ان ایپس کے مینو ورژنوں کے ساتھ بدل سکتے ہیں۔ مرحلہ آپ کی اسکرین سے نہ ملے تو ایپ کی ترتیبات میں **Connectors** تلاش کریں۔

### Claude {#claude}

1. Claude میں **Settings → Connectors** کھولیں اور نیا custom connector شامل کریں۔
2. اوپر والا پتہ پیسٹ کریں۔
3. پوچھے جانے پر Rent Party میں لاگ اِن کریں، پھر اجازت والے صفحے پر منظوری دیں۔

### ChatGPT {#chatgpt}

1. ChatGPT میں **Settings → Connectors** کھولیں۔ بعض اکاؤنٹس میں پہلی بار developer mode چالو کرنا پڑتا ہے۔
2. اوپر والے پتے سے connector شامل کریں۔
3. پوچھے جانے پر Rent Party میں لاگ اِن کریں، پھر اجازت والے صفحے پر منظوری دیں۔

### Claude Code {#claude-code}

```bash
claude mcp add --transport http rentparty https://bgajltrjcqnchwhewouc.supabase.co/functions/v1/mcp
```

پھر Claude Code میں `/mcp` چلائیں، **rentparty** چنیں، اور کھلنے والی براؤزر ونڈو میں لاگ اِن کریں۔

### Cursor {#cursor}

اپنی `mcp.json` میں Rent Party شامل کریں:

```json
{
  "mcpServers": {
    "rentparty": {
      "url": "https://bgajltrjcqnchwhewouc.supabase.co/functions/v1/mcp"
    }
  }
}
```

پہلی بار استعمال پر Cursor لاگ اِن کرنے کو کہے گا۔

## اجازت کا صفحہ کیا پوچھتا ہے؟ {#consent}

کسی اسسٹنٹ کو کچھ بھی دکھانے سے پہلے Rent Party، `https://rentparty.aoneahsan.com/oauth/consent` پر، یہ دکھاتا ہے:

- **درخواست کرنے والی ایپ کون سی ہے،** اور واپسی کا پتہ؛
- **Rent Party کا کون سا اکاؤنٹ** کھلے گا، خاص طور پر اگر کئی Google اکاؤنٹس ہوں؛
- **اسے کیا کرنے کی اجازت ہو،** آسان جملوں میں۔ پڑھنے اور ہٹانے کی اجازت الگ گروہوں اور الگ نشان والے خانوں میں ہیں۔ ہٹانے کا خانہ پہلے سے خالی ہوتا ہے؛
- **منظور کریں** اور **انکار کریں،** ایک ساتھ۔

[دو مرحلہ لاگ اِن](./two-step-sign-in.md) چالو ہو تو منظوری پر کوڈ مانگا جاتا ہے۔ آپ کی طرف سے خودکار منظوری نہیں ہوتی؛ ہر نیا رابطہ اسی صفحے سے گزرتا ہے۔

اسسٹنٹ کو صرف انہی ٹولز کی رسائی ملتی ہے جنہیں آپ نے نشان لگایا۔ صرف پڑھنے کی اجازت دیں تو وہ کچھ ہٹا نہیں سکتا۔

## محفوظ کھیل ہٹانے کا طریقہ کیا ہے؟ {#removing}

اسسٹنٹ ہٹانے کی درخواست **تیار** کر سکتا ہے۔ اسے **انجام** صرف آپ دے سکتے ہیں۔ پرانا محفوظ کھیل ہٹانے کو کہیں تو وہ بتائے گا کون سا کھیل جائے گا، اور Rent Party کا لنک دے گا۔ 10 منٹ کے اندر وہاں تصدیق کریں، ورنہ کھیل محفوظ رہے گا۔

اسی لیے ویب صفحے یا پیسٹ کیے گئے پیغام میں چھپی ہدایت اسسٹنٹ سے آپ کے محفوظ کھیل حذف نہیں کرا سکتی؛ وہ اپنی درخواست کی تصدیق خود نہیں کر سکتا۔

اجازت والے صفحے پر ہٹانے کا خانہ نہ چنا ہو تو وہ درخواست تیار بھی نہیں کر سکتا۔

## اسسٹنٹ کا رابطہ کیسے ختم کریں؟ {#disconnect}

**ترتیبات ← دوسری ایپس ← منسلک ایپس** کھولیں اور اس کی قطار میں **رسائی ختم کریں** چنیں۔ اگلی درخواست پر اس کی رسائی ختم ہو جاتی ہے۔ فہرست ہر ایپ کی اجازتیں، رابطہ بننے اور آخری استعمال کی تاریخ دکھاتی ہے؛ منظوری دیتے ہی نئی ایپ اس میں آ جاتی ہے۔ ایپ منسلک ہونے پر Rent Party آپ کو ای میل بھی بھیجتا ہے۔
