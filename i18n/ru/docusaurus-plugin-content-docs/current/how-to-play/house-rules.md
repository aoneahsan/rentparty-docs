До начала игры выберите готовый набор или включайте домашние правила по одному. Это делается на шаге «Домашние правила» при [начале игры](../intro.md#start-a-game).

:::note[Числа на этой странице]

Они соответствуют текущим настройкам игры. Самые свежие значения всегда показаны на игровой странице [«Как играть»](https://rentparty.aoneahsan.com/how-to-play).

:::

## Какие есть готовые наборы? {#presets}

| Набор | Что он устанавливает |
|---|---|
| Официальные | Знакомые правила без домашних дополнений. |
| Семейная классика | Копилка, бонус за остановку на «Старте» и сделки в любое время. |
| Быстрая игра | Короткий вариант, описанный в разделе [о победе](./rules.md#winning). |
| Турнирные | Официальные правила с обязательными таймерами хода и решений. |

## Какие домашние правила можно включить? {#house-rules}

| Правило | Что оно меняет |
|---|---|
| Копилка | Все налоги, сборы и платежи банку по картам, включая ремонт, идут в копилку. Игрок, попавший на Городскую площадь, забирает всё. |
| Бонус за «Старт» | Дополнительные 200 баксов за остановку точно на «Старте». |
| Сделки только в свой ход | Обмениваться можно только во время своего хода. |
| Ограничение длительности | После выбранного числа раундов или минут победит игрок с наибольшим состоянием. |
| Без аукционов | Улица, которую никто не купил, остаётся у банка. |
| Начальные баксы и зарплата | Выберите свои суммы. |
| Выбор городского налога | Попав на клетку городского налога, заплатите 200 баксов или 10% состояния. Выбрать нужно до подсчёта. |
| Закрытые ставки | Для живых и локальных игр; подробности — [в разделе об аукционах](./rules.md#auctions). За одним устройством каждый вводит ставку тайно, передавая его дальше. |
| Быстрая раздача | Каждый получает от банка 2 случайные карточки собственности. |
| Срок отбыт | После трёх неудачных попыток выбросить дубль выходите из тюрьмы без штрафа. |

Если ваша семья всегда складывала налоги в середину поля и отдавала их тому, кто попадал на тихий угол, правило «Копилка» именно для вас.

## Какие правила допустимы в рейтинговой игре? {#rated-games}

Только официальные или турнирные. Рейтинговая онлайн-игра влияет на ваш рейтинг, когда за каждым местом человек. Подробности — в [разделе онлайн-игры](../online-play.md#rated-games).
