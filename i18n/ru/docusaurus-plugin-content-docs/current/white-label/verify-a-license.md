Любой желающий может проверить версию Rent Party под другим брендом на [странице проверки лицензии](https://rentparty.aoneahsan.com/verify-license). Проверку проводит наш сервис лицензирования.

## Как проверить по ключу? {#by-key}

Введите ключ лицензии. Он начинается с `RENTPARTY-WL-`. Ответ покажет, действует ли лицензия, готовится ли развёртывание или она отозвана, а также открытые сведения: владелец, домены, платформы и срок обновлений. Адрес электронной почты и цена не показываются.

## Как проверить по домену? {#by-domain}

Введите домен, например `play.yourbrand.com`. Каждая лицензированная версия отдаёт файл по адресу `/.well-known/rentparty-white-label-license.json`. Проверка читает этот файл и указанную в нём лицензию.

## Что означают ответы? {#answers}

| Ответ | Значение |
|---|---|
| Действует | Лицензия действительна. |
| Готовится | Лицензия выдана, но версия ещё не запущена. |
| Отозвана | Действие лицензии прекращено из-за использования вне её условий. |
| Домен не покрыт | На домене есть файл лицензии, но эта лицензия не покрывает домен. |
| Нет файла лицензии | Домен не отдаёт файл лицензии Rent Party. |
