Токен доступа — длинный секрет, который ваш код отправляет с каждым запросом в заголовке `Authorization: Bearer <token>`. Вы создаёте его в разделе **Настройки → Другие приложения**, выбираете доступные данные и срок действия. Отозвать токен можно в любой момент. Подключаемое приложение использует OAuth, поэтому передавать ему токен не нужно.

## Как создать токен? {#make-a-token}

1. Откройте **Настройки → Другие приложения → Токены доступа** и выберите **Новый токен**.
2. Дайте ему имя, которое будет понятным и через месяц. *Таблица игровых вечеров* лучше, чем *токен 1*.
3. Выберите разрешения и срок действия.
4. Токен показывается один раз вместе с кнопкой копирования. Сохраните его в надёжном месте, прежде чем закрыть панель.

Затем список показывает имя каждого токена, его разрешения, первые несколько символов, дату создания и время последнего использования — но никогда весь токен. При создании токена вам приходит письмо, поэтому создание без вашего ведома будет заметно.

## Можно ли снова увидеть токен? {#reveal}

Да, в течение **10 минут после входа**. Нажмите **Показать** в строке токена:

| Когда | Что произойдёт |
|---|---|
| После входа прошло меньше 10 минут | Токен появится на экране. |
| Прошло больше 10 минут | Rent Party предложит **Войти снова** и вернёт вас к той же строке. |
| Включён двухэтапный вход | Дополнительно потребуется код из приложения-аутентификатора, даже в пределах 10 минут. |

Зачем это нужно? Долгий вход удобен, но так же может выглядеть чужой доступ к одолженному телефону. Повторный вход подтверждает, что токен запрашиваете вы. Показать токен можно не более 10 раз в час; каждый показ отмечается в учётной записи. Токены никогда не отправляются по почте.

## Что означают разрешения? {#scopes}

Для чтения каждой части ваших данных есть отдельное разрешение. У сохранённых партий есть ещё одно:

| Разрешение | Что разрешает токену |
|---|---|
| `<part>:read` | Читать профиль и статистику, результаты завершённых партий, значки и историю рейтинга или сохранённые партии |
| `saved_games:delete` | Удалить одну из ваших сохранённых партий |

Нет разрешения, которое позволяет изменить партию, профиль или результат. Точные имена разрешений приведены в [файле OpenAPI](./api.md#reference).

**Удаление не следует из чтения.** Разрешение читать сохранённые партии не даёт права их удалять. Удаление выбирается отдельно и изначально выключено. После создания список разрешений токена нельзя расширить: создайте новый токен и отзовите старый. Токен не может получить права команды.

## Как долго действует токен? {#expiry}

Вы выбираете **30, 90 или 365 дней**. Rent Party напишет вам за семь дней до окончания срока. После него каждый запрос с токеном получит ответ `401`.

## Как заменить или отозвать токен? {#rotate-and-revoke}

- **Заменить** создаёт новый токен. Старый работает ещё 24 часа, чтобы вы успели обновить код, а затем отзывается. До этого оба видны в списке.
- **Отозвать** сразу прекращает действие токена. Следующий запрос с ним получит `401`. Для подтверждения нажмите кнопку дважды; отдельного окна нет.

При удалении учётной записи Rent Party отзываются все токены, подключения приложений и вебхуки.

## Как приложение подключается без токена? {#oauth}

Через OAuth 2.1 — так же подключается ИИ-помощник. Приложение направит вас на страницу согласия Rent Party по адресу `https://rentparty.aoneahsan.com/oauth/consent`. Там показаны:

- имя приложения и адрес возврата;
- учётная запись Rent Party, к которой оно просит доступ;
- запрашиваемые права простыми словами; чтение и удаление разделены и имеют отдельные флажки, удаление изначально не отмечено;
- кнопки **Разрешить** и **Отклонить** рядом друг с другом.

Если включён двухэтапный вход, для разрешения потребуется код. Затем приложение появится в разделе **Настройки → Другие приложения → Подключённые приложения**, где его можно переименовать или отозвать. После отзыва доступ прекращается со следующего запроса. Подробнее: [ИИ-помощники](./mcp.md#consent).

## Сколько запросов можно отправить? {#rate-limits}

Для каждого токена и приложения действует лимит **120 запросов в минуту**. Кроме того, у всей учётной записи есть дневной лимит согласно вашему плану. Все токены и приложения делят его: создание дополнительных токенов не увеличит лимит. В разделе **Настройки → Другие приложения** показаны лимит вашего плана и сегодняшнее использование.

Каждый ответ содержит три заголовка:

| Заголовок | Значение |
|---|---|
| `RateLimit-Limit` | Сколько запросов разрешено в текущем окне |
| `RateLimit-Remaining` | Сколько запросов осталось |
| `RateLimit-Reset` | Через сколько секунд начнётся новое окно |

При превышении лимита вы получите `429` с заголовком `Retry-After`. Подождите указанное число секунд и повторите запрос.

При одновременной отправке большого числа запросов платформа размещения может вернуть `546` ещё до того, как запрос дойдёт до Rent Party. Отправляйте их последовательно или небольшими группами; после `546` повторите попытку через секунду.

## Как выглядит ошибка? {#errors}

На каждом маршруте ошибки имеют одинаковый формат:

```json
{
  "error": {
    "code": "reauth_required",
    "message": "Sign in again to see this token.",
    "details": { "max_age_seconds": 600 },
    "correlation_id": "…"
  }
}
```

В коде ориентируйтесь на `code`. Поле `message` предназначено для человека и может изменить формулировку. При обращении в поддержку по поводу ошибки укажите `correlation_id`: по нему мы найдём именно этот запрос.

| Статус | Обычная причина |
|---|---|
| `401` | Токена нет, он неверный, отозван или просрочен |
| `403` | У токена нет нужного разрешения (оно указано в `details`) либо требуется повторный вход |
| `404` | Запись с таким идентификатором вам недоступна или не существует; чужая запись также возвращает этот статус |
| `429` | Превышен лимит запросов. См. `Retry-After` |

Полный список кодов приведён в [файле OpenAPI](./api.md#reference).
