Вебхук — это подписанный запрос `POST`, который Rent Party отправляет на ваш адрес при событии в вашей учётной записи. Партия закончилась — сервер узнаёт, кто победил. Добавьте адрес в разделе **Настройки → Другие приложения → Вебхуки**, выберите события и проверяйте подпись каждого запроса, чтобы убедиться, что он пришёл от нас.

## Какие события доступны? {#events}

| Событие | Когда отправляется |
|---|---|
| `game.finished` | Завершилась партия, в которой вы участвовали |
| `achievement.earned` | Вы получили значок |
| `saved_game.created` | Партия сохранена в вашей учётной записи |
| `saved_game.deleted` | Одно из ваших сохранений удалено |
| `webhook.test` | Вы нажали **Отправить тестовое событие** |

Полный состав данных каждого события указан в [файле OpenAPI](./api.md#reference). Мы не дублируем его здесь, чтобы сведения не расходились.

## Какие адреса принимаются? {#addresses}

- Только `https://` на порту 443 или 8443, без имени пользователя и пароля в адресе.
- Частные и локальные адреса не принимаются: `localhost`, `127.0.0.1`, `10.x.x.x`, `192.168.x.x`, локальные адреса канала и домены, указывающие на них. Проверка проводится при сохранении адреса и перед каждой отправкой. Перенаправление на частный адрес также отклоняется.
- Ваш сервер должен ответить в течение 10 секунд.

## Что содержится в запросе? {#headers}

Rent Party следует спецификации [Standard Webhooks](https://www.standardwebhooks.com/). Каждый запрос содержит три заголовка:

| Заголовок | Содержимое |
|---|---|
| `webhook-id` | Идентификатор события. При повторной доставке он не меняется; используйте его, чтобы не обработать событие дважды. |
| `webhook-timestamp` | Время отправки в секундах от начала 1970 года. |
| `webhook-signature` | `v1,` и подпись HMAC-SHA256 в base64. Подписей может быть несколько, через пробел. |

Секрет подписи начинается с `whsec_`. Повторно показать его можно по тому же [правилу 10 минут](./authentication.md#reveal), что и токен. Команда **Заменить** создаёт новый секрет и в течение 24 часов подписывает запросы обоими, чтобы принимающий сервер продолжал работать, пока вы обновляете секрет.

## Как проверить запрос? {#verify}

Сначала проверьте подпись, затем разбирайте данные. Подписаны исходные байты запроса: если разобрать JSON и снова записать его, подпись не совпадёт.

Ниже использованы библиотеки Standard Webhooks: `standardwebhooks` 1.3.0 в npm и PyPI и `standard-webhooks/standard-webhooks` 1.3.0 в Packagist; версии проверены 19 ноября 2026 года.

### Node {#node}

```js
import { Webhook } from 'standardwebhooks';

const wh = new Webhook(process.env.RENTPARTY_WEBHOOK_SECRET); // the whsec_… value

app.post('/hooks/rentparty', express.raw({ type: 'application/json' }), (req, res) => {
  let event;
  try {
    event = wh.verify(req.body, req.headers); // throws on a bad signature or a stale timestamp
  } catch {
    return res.sendStatus(400);
  }
  if (seenBefore(req.headers['webhook-id'])) return res.sendStatus(200);
  queue.add(event); // answer quickly, do the work afterwards
  res.sendStatus(200);
});
```

### Python {#python}

```python
from standardwebhooks.webhooks import Webhook
wh = Webhook(os.environ["RENTPARTY_WEBHOOK_SECRET"])
payload = wh.verify(request.get_data(), dict(request.headers))
```

### PHP {#php}

```php
$wh = new \StandardWebhooks\Webhook(getenv('RENTPARTY_WEBHOOK_SECRET'));
$payload = $wh->verify(file_get_contents('php://input'), getallheaders());
```

### Любой язык {#any-language}

1. `secret = base64decode(the whsec value without its "whsec_" prefix)`.
2. `signed = webhook-id + "." + webhook-timestamp + "." + raw body` (именно полученные байты).
3. `expected = base64(HMAC_SHA256(secret, signed))`.
4. Сравните `expected` с каждым значением `v1,` из `webhook-signature` за постоянное время. Достаточно одного совпадения.
5. Отклоните запрос, если `|now − webhook-timestamp| > 300`.

## Что будет, если сервер не ответит? {#retries}

Любой ответ `2xx` означает доставку. Другой статус, тайм-аут или отказ соединения считаются неудачной попыткой, и Rent Party пробует снова:

| Попытка | Время отправки |
|---|---|
| 1 | Сразу |
| 2 | Через 5 секунд |
| 3 | Через 5 минут |
| 4 | Через 30 минут |
| 5 | Через 2 часа |
| 6 | Через 5 часов |
| 7 | Через 10 часов |
| 8 | Ещё через 10 часов |

Адрес отключается в трёх случаях:

- **`410 Gone`** — сразу. Возвращайте этот статус, если намеренно закрыли адрес.
- **Все восемь попыток не удались** для одного события.
- **Пять дней подряд доставка на адрес не удавалась.**

После отключения Rent Party отправит вам письмо с последней ошибкой и ссылкой для повторного включения адреса.

## Как проверить и повторить доставку? {#test-and-replay}

- **Отправить тестовое событие** немедленно отправляет `webhook.test` на адрес.
- **Журнал доставки** для адреса перечисляет попытки: статус, номер, код ответа, длительность и время следующего повтора. Он обновляется по мере доставки без перезагрузки страницы.
- **Повторить** отправляет одну доставку снова с тем же `webhook-id`. После сбоя можно повторить все пропущенные доставки, начиная с выбранного времени, до 1000 за один раз.
- **Приостановить** останавливает отправку на адрес, пока вы её не возобновите.
