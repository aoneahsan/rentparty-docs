Один способ входа через Google на всех экранах, между которыми переходит игра.

## Что делает Capacitor Auth Manager? \{#capacitor-auth-manager-fact-1}

Capacitor Auth Manager предоставляет единый вызов входа через Google для браузера, Android и iOS.

## Что ещё умеет Capacitor Auth Manager? \{#capacitor-auth-manager-fact-2}

Для его работы Firebase не нужен.
