Используйте один интерфейс хранения для веб- и нативных сохранений.

## Что делает Strata Storage? \{#strata-storage-fact-1}

Strata Storage даёт единый API для localStorage, IndexedDB, файлов cookie и нативного хранилища.

## Что ещё умеет Strata Storage? \{#strata-storage-fact-2}

Пакет не имеет зависимостей и работает в браузере, на iOS и Android.
