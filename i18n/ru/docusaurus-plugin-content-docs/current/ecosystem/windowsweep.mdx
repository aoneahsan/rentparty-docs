Посмотрите каждый путь очистки Windows, прежде чем решать, что удалить.

## Что делает windowsweep? \{#windowsweep-fact-1}

windowsweep — утилита очистки Windows из командной строки: сначала пробный запуск, личные файлы выбираются по одному, запуск через npx без установки.

## Что ещё умеет windowsweep? \{#windowsweep-fact-2}

Утилита называет каждый путь, прежде чем что-либо с ним делать.
