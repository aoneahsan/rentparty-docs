لا يحتاج أحد إلى ترك Board Game Arena. فيها مئات الألعاب، بينما تقدم Rent Party لعبة واحدة. تعالوا إليها في ليلة تبادل العقارات، واحتفظوا بحساباتكم هناك لكل ما عدا ذلك.

هنا، لا تحتاج إلى خطة مدفوعة لفتح طاولة. ويمكنكم تمرير هاتف واحد بين اللاعبين، ومواجهة شخصيات الحاسوب، أو فتح غرفة عبر الإنترنت.

## اشتراك Premium وسجل ألعابك \{#move}

يبقيان في Board Game Arena.

## اللعب بالأدوار كما اعتادت مجموعتك \{#table}

1. سجّل الدخول بحساب Google عبر [ابدأ لعبة](https://rentparty.aoneahsan.com/play)، واختر اللعب عبر الإنترنت.
2. اختر اللعب على مدى أيام وحدد مهلة 8 أو 12 أو 24 أو 48 ساعة [لكل دور](../online-play.md#modes).
3. أرسل [الدعوة](../online-play.md#invites). لا تحدد خطتك إن كنت تستطيع فتح طاولة؛ بل تحدد [حدودها](../plans-and-pricing.md#limits) عدد الألعاب التي تشغّلها في وقت واحد.

## لعبة مختلفة كل أسبوع؟ \{#stay}

Board Game Arena أنسب لذلك، بطاولات مباشرة وبالأدوار لمئات الألعاب.

## وضع اللعبتين اليوم \{#facts}

تصف Board Game Arena وضع Premium للعب على جهاز واحد. لم تذكر صفحاتها إن كانت توفر لاعبين حاسوبيين، أو إيقافًا مؤقتًا، أو مظاهر تجمعها، أو صنع لوحك الخاص، أو تطبيقات Android وiOS، أو إعلانات من جهات خارجية؛ لذلك لا نعرض صفوفًا عن هذه الأمور.
