مسار واحد لتسجيل الدخول بحساب Google عبر الشاشات التي ينتقل بينها التطبيق.

## ماذا يقدم Capacitor Auth Manager؟ \{#capacitor-auth-manager-fact-1}

يوفر Capacitor Auth Manager استدعاءً واحدًا لتسجيل الدخول بحساب Google على الويب وAndroid وiOS.

## ماذا يقدم Capacitor Auth Manager أيضًا؟ \{#capacitor-auth-manager-fact-2}

لا يتطلب Firebase اعتمادًا برمجيًا.
