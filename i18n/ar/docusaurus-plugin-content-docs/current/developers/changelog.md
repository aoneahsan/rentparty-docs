تُسجل هنا تغييرات API وخادم MCP والويب هوك، من الأحدث إلى الأقدم. إصدار API جزء من عنوانه، `/v1`، ويصف [ملف OpenAPI](./api.md#reference) الإصدار الذي يقع تحته دائمًا.

تجد تغييرات الأدلة نفسها في [الجديد](/blog).

## 19 نوفمبر 2026 {#2026-11-19}

- مفاتيح الوصول تحت الإعدادات ← التطبيقات الأخرى، وواجهة `/v1` مع ملف OpenAPI، وخادم MCP لمساعدي الذكاء الاصطناعي، وويب هوك للألعاب المنتهية والشارات والألعاب المحفوظة، والتحقق بخطوتين تحت الإعدادات ← الأمان.
