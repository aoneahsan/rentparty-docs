API, MCP सर्वर और वेबहुक में हर बदलाव यहाँ सबसे नया पहले लिखा जाता है। API का संस्करण उसके पते `/v1` में है। [OpenAPI फ़ाइल](./api.md#reference) हमेशा अपने पते वाले संस्करण को समझाती है।

गाइड में बदलाव [नई बातें](/blog) पर हैं।

## 19 नवंबर 2026 {#2026-11-19}

- Settings → Other apps में एक्सेस टोकन, OpenAPI फ़ाइल वाली `/v1` API, AI सहायकों के लिए MCP सर्वर, पूरे खेलों, बैज और सहेजे खेलों के वेबहुक, और Settings → Security में दो चरणों वाला साइन इन।
