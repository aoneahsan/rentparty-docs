Mettez une seule application Android hors ligne tout en gardant le téléphone connecté.

## Que fait NetCage ? \{#netcage-fact-1}

NetCage peut bloquer le Wi-Fi et les données mobiles d’une application Android choisie sans couper la connexion du reste du téléphone.

## Qu’apporte aussi NetCage ? \{#netcage-fact-2}

Une règle peut viser le Wi-Fi, les données mobiles ou les deux.
