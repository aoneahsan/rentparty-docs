Un seul parcours de connexion Google sur les écrans entre lesquels un jeu peut circuler.

## Que fait Capacitor Auth Manager ? \{#capacitor-auth-manager-fact-1}

Capacitor Auth Manager fournit un appel de connexion Google unique pour le web, Android et iOS.

## Qu’apporte aussi Capacitor Auth Manager ? \{#capacitor-auth-manager-fact-2}

Son utilisation ne nécessite pas Firebase comme dépendance.
