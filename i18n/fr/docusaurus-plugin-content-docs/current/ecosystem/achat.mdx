Gardez le contact entre les soirées de jeu avec les personnes choisies, sans numéro de téléphone.

## Que fait AchatAI ? \{#achat-fact-1}

AChat est une messagerie web et Android pour les personnes que vous choisissez.

## Qu’apporte aussi AchatAI ? \{#achat-fact-2}

On peut retrouver une personne par son nom d’utilisateur, un lien d’invitation ou un code QR, sans numéro de téléphone.
