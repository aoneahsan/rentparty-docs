## Que fait Empora ? \{#empora-fact-1}

Empora rassemble des modules de boutique WooCommerce dans une seule extension WordPress.

## Qu’apporte aussi Empora ? \{#empora-fact-2}

Le commerçant choisit les modules à activer.
