Rien à transférer. Un jeu de plateau ne conserve pas de données que vous auriez besoin d'importer : pour découvrir Rent Party, il suffit de réunir vos joueurs autour d'une table. Chaque guide explique comment faire et dans quels cas l'autre jeu vous conviendra mieux.

Les tarifs et caractéristiques ont été vérifiés sur les pages officielles de chaque jeu le 27 novembre 2026. Pour comparer côte à côte les propriétés des deux jeux, consultez la [comparaison sur le site Rent Party](https://rentparty.aoneahsan.com/compare).

## Quel jeu connaissez-vous déjà ? \{#guides}

- [Rento](./rento.mdx) : sur téléphone, PC et console
- [Richup.io](./richup-io.mdx) : une autre table dans le navigateur
- [Rumble Avenue](./rumble-avenue.mdx) : une table sans compte
- [Business Tour](./business-tour.mdx) : sur Steam et iPhone, avec un éditeur de cartes
- [Quadropoly](./quadropoly.mdx) : jeu solo sur Android, avec huit niveaux d'IA
- [Get Rent (Landlord GO)](./get-rent.mdx) : de vrais bâtiments sur une vraie carte
- [Board Game Arena](./board-game-arena.mdx) : des centaines de jeux sous licence
- [Tabletopia](./tabletopia.mdx) : une table virtuelle avec éditeur
- [Tabletop Simulator](./tabletop-simulator.mdx) : un bac à sable 3D sur PC
- [The Jackbox Party Packs](./jackbox-party-packs.mdx) : des manches rapides sur un écran partagé
- [Ludo King](./ludo-king.mdx) : une course familiale d'une dizaine de minutes

## Quelles sont encore nos limites ? \{#limits}

Autant vous les dire directement. Il n'y a ni éditeur de plateau ni application iOS ; sur iPhone, vous jouez dans le navigateur. Rent Party est disponible sur Google Play pour Android. Nous n'affichons pas de publicité de tiers, mais un petit panneau présente nos autres applications sur certaines pages.

À vous de choisir quand commencer : [lancer une partie](https://rentparty.aoneahsan.com/play).
