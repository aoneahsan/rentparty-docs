Les changements de l'API, du serveur MCP et des webhooks apparaissent ici, du plus récent au plus ancien. La version de l'API figure dans son adresse, `/v1`, et le [fichier OpenAPI](./api.md#reference) décrit toujours la version correspondante.

Les changements de cette documentation sont annoncés dans les [nouveautés](/blog).

## 19 novembre 2026 {#2026-11-19}

- Jetons d'accès dans Paramètres → Autres applications ; API `/v1` et son fichier OpenAPI ; serveur MCP pour les assistants IA ; webhooks pour les parties terminées, les badges et les sauvegardes ; connexion en deux étapes dans Paramètres → Sécurité.
